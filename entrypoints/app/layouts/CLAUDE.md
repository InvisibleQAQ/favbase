# app/layouts

仪表盘布局系统。

## 模块结构

- `core/layout-section.tsx` — 布局骨架：sidebar + sidebarContainer(header+main+footer)，注入 CSS vars via GlobalStyles
- `core/header-section.tsx` — 粘性 AppBar + 滚动毛玻璃效果（backdrop-filter 用 `var(--layout-header-blur)`，值在 `core/css-vars.ts` 定义为 8px），slots: leftArea/rightArea/centerArea
- `core/main-section.tsx` — flex column 主内容区
- `core/css-vars.ts` — 布局 CSS 变量（nav-zIndex/header-height/nav-width）
- `dashboard/layout.tsx` — DashboardLayout：通过必填 `navigation` prop 接收 app composition root 已解析的不可变导航，同一份数据传给 NavDesktop + NavMobile；布局本身不读 onboarding。读取 `sidebarPinnedStorage` 控制侧边栏 pinned/unpinned 状态，Header 左侧 toggle 按钮（lg+ 可见）切换，CSS 变量 `--layout-nav-vertical-width` 动态切换 280px/72px。Header `rightArea` slot 挂 `BackgroundJobsIndicator` + `HeaderActions`（一个 flex Box 包裹）。**常驻挂载 `useJobsBadge()`**（`app/hooks/use-jobs-badge.ts`）把运行中任务数写到工具栏图标 badge——与 indicator 同源同生命周期
- `dashboard/header-actions.tsx` — HeaderActions：Header 右侧控件（暗色旋钮 + 语言切换 + GitHub 入口）。**`ThemeToggleSwitch`**（最左）`太阳 | iOS 开关 | 月亮` 三件套：`useColorScheme()` 读 `mode`/`systemMode`，`resolved = mode==='system'?systemMode:mode`（mounted 前 `mode` 为 undefined，回退读 `<html data-color-scheme>`——即 index.html FOUC 脚本已设的值，避免翻转），`ThemeSwitch`（styled MUI `Switch`，40×22 iOS 药丸，thumb 18）`checked={resolved==='dark'}`，`onChange` → `setMode(checked?'dark':'light')`，checked（thumb 右）轨道 `grey[700]` 暖墨（夜色由月亮图标自带，控件不再硬编码靛蓝），unchecked 轨道 `grey[400]`，thumb `common.white`。**太阳/月亮两图标恒常并列显示**（非单按钮二选一），均为 `icon-sets.ts` 的 `custom:*` **多色 SVG 离线图标**（真实色值仿 flagpack）：太阳黄芯 `#FFD24D`+橙光线 `#FF9800`；月亮靛蓝月牙 `#5C6BC0`+金色星点 `#FFD24D`（月牙用饱和靛蓝而非奶白，否则在亮态浅色 header 上与白底重合不可见）。**切换动画**：`handleToggle` 用 **View Transitions API**（Chromium）做从开关中心展开的圆形揭示——`flushSync(()=>setMode(next))` 强制 MUI 在过渡回调内同步提交 `data-color-scheme`（否则 "after" 快照仍是旧主题），`transition.ready` 后用 WAAPI 对 `::view-transition-new(root)` 动画 `clip-path: circle(0→endRadius)`（420ms ease-in-out，endRadius=到最远视口角的距离）；`prefers-reduced-motion` 或不支持 `startViewTransition` 时降级为瞬时 `setMode`。伴随 pseudo-element CSS 在 `app/global.css`（关默认 cross-fade + new 快照置于 old 之上）。ThemeProvider 保留 `disableTransitionOnChange`（快照过渡下要瞬时换色，避免逐元素 CSS transition 干扰）。a11y 走 `slotProps.input['aria-label']` + Tooltip，i18n key `header.themeAria`。**语言按钮为国旗样式**：触发按钮显示**当前生效语言**（`useTranslation()` 的 `locale`）的国旗（`flagpack:cn`/`flagpack:gb`，`FLAG_WIDTH×FLAG_HEIGHT=24×18` 保 4:3 + `borderRadius:0.5`），点开 MUI `Menu` 两项（`settings.languageZhCN/En`，各「国旗 + 语言名」），当前项尾部一个 `primary.main` 小圆点。**选中态与触发国旗均按解析后 `locale` 判定（非 `preference`）**，故 `preference='auto'` 时也正确高亮/显旗；点选 `setLocale(value)` 写入显式偏好（`SupportedLocale`）并关闭。**header 不含 auto 项**——auto 保留在「设置>通用」。国旗是多色 SVG 离线注册（`icon-sets.ts` 的 `flagpack:*`，Windows Chrome 不把 emoji 国旗渲染成国旗，故必须 SVG）。`useTranslation()` 订阅使切换后 flag/aria-label/tooltip re-render。GitHub 按钮 `IconButton component="a"`（`mdi:github`）新标签打开 `REPO_URL`。i18n key `header.githubAria`/`header.languageAria`/`header.themeAria`
- `dashboard/background-jobs-indicator.tsx` — 全局未完成任务提醒：订阅模块级 `useRunningJobs()`，running/pausing/paused 都保留在 Header；全部 paused 时显示 Pause 图标，否则显示 spinner。Chip label 只给任务数，Tooltip 逐条显示平台、`sync|extract|embed|tag|transcribe` 类型、done/total 及 pausing/paused phase。**常驻 Header（跨路由不卸载）** 是关键：平台 section 切走后任务和提醒仍可观察。i18n key `backgroundJobs.reminder`、`backgroundJobs.kind.*`、`backgroundJobs.phase.*`。NavMobile（Drawer 抽屉，pathname 变化自动关闭，始终 pinned 模式）+ NavContent（顶部品牌行复用 `/icon/128.png` 36px 项目 logo；顶层项：`item.children` 走 `CollectionsBranch`，否则走 `NavLeafButton`）。**一级嵌套**：`CollectionsBranch`（Collections 父项）pinned 时把图标/标题作为 `/collections` 的 `RouterLink`，右侧独立 chevron `IconButton` 只控制 MUI `Collapse`（`aria-expanded`/`aria-controls`）；`/collections*` 路由下 active 高亮 + 自动展开。**active 态三处共用 `navActiveSx(theme)`**：`primary.lighter` 淡洗底 + `text.primary` 600 + 仅图标槽（`.favbase-nav-icon`）染珊瑚——珊瑚不做文字（2.5:1）。圆角 ×1。unpinned(72px) 退化为纯图标 + Tooltip，点击跳转 `/collections`，不展开树。展开后子项经 `NavChildLeaf` 渲染为**缩进的叶子链接**（`component={RouterLink}` 指向 `child.path`，同一 `navActiveSx` 高亮，若 `child.icon` 存在则在文字前渲染 20px 固定图标槽）。**子叶 active 判定 = 最长前缀匹配**（`nav-active.ts` 的 `findActiveChildPath`，段边界前缀 + 最长者胜，兄弟叶互斥）——改名后 sibling 叶（`/collections/bilibili`、`/collections/github`）不再互相前缀，天然互斥；最长者胜仍用于把嵌套详情路由 `/collections/bilibili/:id` 归属 bilibili 叶。**鱼骨连接线**：每个叶子自己用 `::before`（竖脊段）+ `::after`（横肋 `FISHBONE_RIB=14px`）画出与父项的连接，最后一个叶子竖脊只到横肋中点收成 L 形拐角（避免竖线拖尾）；竖脊对齐父项图标竖轴（子容器 `ml: 3.5` = 父图标中心 28px），叶子按钮 `ml` 让高亮 pill 让开横肋区。子项来自 `collectionPlatformRegistry`，**不再往下展开收藏夹**——收藏夹列表留在平台页内过滤器。nav 不消费收藏夹数据，无全局 provider
- `dashboard/nav.tsx` 平台叶子颜色契约 — `nav-config.tsx` 从 `collectionPlatformRegistry` 将 `child.platform` 传入 `NavChildLeaf`；非 active 平台图标槽消费 `theme.vars.palette.platform[platform]`，active 由共享 `navActiveSx` 覆盖为珊瑚，Platform Request 外链保持禁用色。平台身份色不用于导航文字、背景或连接线。
- `nav-active.ts` — `findActiveChildPath(pathname, childPaths)` 纯函数（单测 `nav-active.test.ts`）：兄弟子叶的 active 路径解析，段边界前缀匹配（`===` 或 `path/` 前缀）+ 最长匹配胜出，无匹配返回 null
- `dashboard/content.tsx` — DashboardContent：Container maxWidth + dashboard padding CSS vars
- `nav-config.tsx` — `createNavData(preferredPlatforms)` 是导航策略唯一入口；顶层顺序固定为 Collections、Analytics（`/`）、Chat、Settings。从 `app/collection-platform-registry.ts` 的 canonical 元数据稳定分区，选中平台在前、未选平台在后，两组内部保持 registry 顺序且全部平台恰好一次；末尾追加**Platform Request 外链叶子**（`external: true`，`path` 直接放 `lib/repo.ts` 的预填 new-issue URL——它是动作不是平台，刻意不进 registry）。模块不导出可变/静态 nav 单例。`NavItem.external` 让 `NavChildLeaf` 渲染 `<a target="_blank" rel="noopener noreferrer">` 而非 RouterLink：文字 `text.disabled` 淡化 + 尾部 `eva:diagonal-arrow-right-up-fill` 外链箭头，active 匹配对 https URL 天然不命中故永不高亮

## 约定

- 侧边栏 Pin/Unpin: `sidebarPinnedStorage`（`lib/storage/ui-state.ts`），布尔值存储在 `local:sidebarPinned`（默认 true）。DashboardLayout 读取并通过 toggle 按钮切换。Pinned=280px 展开（图标+文字），Unpinned=72px 图标栏（MUI Tooltip 显示菜单名）。Mobile（md 以下，<900px）不受影响，始终 Drawer 模式
- nav 嵌套：主 sidebar 只做**一级嵌套**（Collections 父项 → 平台叶子链接），止于平台名，不展开收藏夹。收藏夹数据仍由各平台 section 拥有，nav 不读取。`Onboarding Platform Preference` 仅决定子叶优先级，禁止隐藏平台或反向重排 registry；新增平台更新 `lib/collections/platforms.ts` + `app/collection-platform-registry.ts` 后会自动落在未选组。active 互斥由 `nav-active.ts` 最长前缀匹配保证
