# app/layouts

仪表盘布局系统（docs/23 Phase 2 已按 Minimal v7 shell 几何收敛，2026-08-28）。

## Shell 几何契约

CSS 变量是 shell 的唯一 owner，页面只消费变量名，不复制数值：

| 变量 | 值 | owner |
| --- | --- | --- |
| `--layout-header-mobile-height` / `-desktop-height` | 64px / 72px（`layoutQuery`=md 切换） | `core/css-vars.ts` |
| `--layout-header-blur` | 8px，仅滚动后启用 | `core/css-vars.ts` |
| `--layout-nav-mobile-width` | 288px | `core/css-vars.ts` |
| `--layout-nav-vertical-width` | 300px pinned / 88px compact（`NAV_VERTICAL_WIDTH`） | `dashboard/css-vars.ts` |
| `--layout-nav-item-height` / `-child-item-height` / `-compact-item-size` | 44px / 40px / 44px | `dashboard/css-vars.ts` |
| `--layout-dashboard-content-pt` / `-pb` / `-px` | 1 / 8 / 5 spacing 单位（8/64/40px） | `dashboard/css-vars.ts` |
| `--layout-transition-easing` / `-duration` | linear / 120ms | `dashboard/css-vars.ts` |

- 变量挂在 `:root`（非 `body`），因此 `html { scroll-padding-top: var(--layout-header-*-height) }` 能读到 Header 高度：焦点/锚点滚动不会被 sticky Header 遮挡。
- Scroll owner 唯一：document 滚动页面；侧栏 `position: fixed` 自己滚（`nav` 元素 `overflowY: auto`）；Header `position: sticky`；`<main>` 只是流式布局。`LayoutSidebarContainer` 设 `minWidth: 0`，宽内容缩容器而不是撑出水平滚动。
- Content gutter：`DASHBOARD_CONTENT_QUERY`（`lg`）起 40px；以下走 MUI Container 默认 24px（sm+）/16px（xs）。Header 容器经 `slotProps.container` 在同一断点用同一变量，Header 首个图标与路由标题共享左边缘。
- `sections/chat/chat-view.tsx` 消费 `--layout-header-*-height`、`--layout-nav-zIndex`、`--layout-nav-vertical-width`，变量名属契约。`dashboard/css-vars.test.ts` 锁全部数值。

## 模块结构

- `core/layout-section.tsx` — 布局骨架：sidebar + sidebarContainer(header+main+footer)，经 GlobalStyles 把 CSS vars 注入 `:root` 并设 `html` scroll-padding；`layoutQuery` prop 决定 scroll-padding 的桌面切换点（与 Header 同步）
- `core/header-section.tsx` — 粘性 AppBar，静止时透明；滚动后 `::before` 淡入 8px blur + 80% ground wash + `divider` hairline（`disableElevation` 去掉浮影）。slots: leftArea/rightArea/centerArea；`slotProps.container` 透传给 MUI Container（dashboard 用它对齐 gutter）
- `core/main-section.tsx` — flex column 主内容区
- `core/css-vars.ts` — header/mobile drawer 变量（见上表）
- `dashboard/css-vars.ts` — nav 宽度/行高与 content padding 变量；`NAV_VERTICAL_WIDTH` 常量
- `dashboard/content.tsx` — DashboardContent：Container maxWidth + dashboard padding CSS vars；导出 `DASHBOARD_CONTENT_QUERY`
- `dashboard/layout.tsx` — DashboardLayout：通过必填 `navigation` prop 接收 app composition root 已解析的不可变导航，同一份数据传给 NavDesktop + NavMobile；布局本身不读 onboarding。读取 `sidebarPinnedStorage` 控制侧边栏 pinned/compact，Header 左侧 toggle 按钮（桌面可见，`aria-label`=`header.sidebarToggleAria` + `aria-expanded` + Tooltip）切换 `--layout-nav-vertical-width` 300/88px；移动端换成菜单按钮（`header.menuAria` + Tooltip），其 ref 作为 `NavMobile.onExited` 的焦点归位目标。Header `rightArea` slot 挂 `BackgroundJobsIndicator` + `HeaderActions`（一个 `minWidth: 0` 的 flex Box，390px 下 chip 先收缩截断，控件不重叠）。**常驻挂载 `useJobsBadge()`**（`app/hooks/use-jobs-badge.ts`）把运行中任务数写到工具栏图标 badge——与 indicator 同源同生命周期。`layout.test.tsx` 锁 toggle 的 aria 与 storage 写入、移动 Drawer 路由关闭 + 焦点回菜单按钮
- `dashboard/header-actions.tsx` — HeaderActions：Header 右侧控件（暗色旋钮 + 语言切换 + GitHub 入口）。**`ThemeToggleSwitch`**（最左）`太阳 | iOS 开关 | 月亮` 三件套：`useColorScheme()` 读 `mode`/`systemMode`，`resolved = mode==='system'?systemMode:mode`（mounted 前 `mode` 为 undefined，回退读 `<html data-color-scheme>`——即 index.html FOUC 脚本已设的值，避免翻转），`ThemeSwitch`（styled MUI `Switch`，40×22 iOS 药丸，thumb 18）`checked={resolved==='dark'}`，`onChange` → `setMode(checked?'dark':'light')`，checked（thumb 右）轨道 `grey[700]` 暖墨（夜色由月亮图标自带，控件不再硬编码靛蓝），unchecked 轨道 `grey[400]`，thumb `common.white`。**太阳/月亮两图标恒常并列显示**（非单按钮二选一），均为 `icon-sets.ts` 的 `custom:*` **多色 SVG 离线图标**（真实色值仿 flagpack）：太阳黄芯 `#FFD24D`+橙光线 `#FF9800`；月亮靛蓝月牙 `#5C6BC0`+金色星点 `#FFD24D`（月牙用饱和靛蓝而非奶白，否则在亮态浅色 header WAAPI 对 `::view-transition-new(root)` 动画 `clip-path: circle(0→endRadius)`（420ms ease-in-out，endRadius=到最远视口角的距离）；`prefers-reduced-motion` 或不支持 `startViewTransition` 时降级为瞬时 `setMode`。伴随 pseudo-element CSS 在 `app/global.css`（关默认 cross-fade + new 快照置于 old 之上）。ThemeProvider 保留 `disableTransitionOnChange`（快照过渡下要瞬时换色，避免逐元素 CSS transition 干扰）。a11y 走 `slotProps.input['aria-label']` + Tooltip，i18n key `header.themeAria`。**语言按钮为国旗样式**：触发按钮显示**当前生效语言**（`useTranslation()` 的 `locale`）的国旗（`flagpack:cn`/`flagpack:gb`，`FLAG_WIDTH×FLAG_HEIGHT=24×18` 保 4:3 + `borderRadius:0.5`），点开 MUI `Menu` - `dashboard/background-jobs-indicator.tsx` — 全局未完成任务提醒：订阅模块级 `useRunningJobs()`，running/pausing/paused 都保留在 Header；全部 paused 时显示 Pause 图标，否则显示 spinner。Chip label 只给任务数，Tooltip 逐条显示平台、`sync|extract|embed|tag|transcribe` 类型、done/total 及 pausing/paused phase。**常驻 Header（跨路由不卸载）** 是关键：平台 section 切走后任务和提醒仍可观察。Chip `maxWidth` xs 136 / sm 320 + `flexShrink: 1`：390px 预算下它先让位。i18n key `backgroundJobs.reminder`、`backgroundJobs.kind.*`、`backgroundJobs.phase.*`
- `dashboard/nav.tsx` — NavDesktop（fixed 侧栏，pinned `px: 2`；compact 用 `calc((宽度 - 44px)/2)` 把 44×44 方形目标居中）+ NavMobile（Drawer，pathname 变化自动关闭，始终 pinned 模式；**焦点契约同 Chat history 44px、`pl 1.5 / gap 1.5 / pr 1`（Minimal 12/12/8）、圆角 1（8px）；平台子行 `--layout-nav-child-item-height` 40px；compact 目标 `--layout-nav-compact-item-size` 44px 且必须有右侧 Tooltip（MUI Tooltip 把 title 写成 `aria-label`，图标链接保有可读名）。标题统一 `NAV_TITLE_SX` 单行截断，最长 zh/en 标签不换行不溢出。**一级嵌套**：`CollectionsBranch`（Collections 父项）pinned 时把图标/标题作为 `/collections` 的 `RouterLink`，右侧独立 chevron `IconButton`（44×44）只控制 MUI `Collapse`（`aria-expanded`/`aria-controls`）；`/collections*` 路由下 active 高亮 + 自动展开。**active 态三处共用 `navActiveSx(theme)`**：`primary.lighter` 淡洗底 + `text.primary` 600 + 仅图标槽（`.favbase-nav-icon`）染珊瑚——珊瑚不做文字（2.5:1）；active 行 hover 用 `varAlpha(primary.mainChannel, 0.24)` 加深，与静止 active 可区分；普通 hover 走 `action.hover`；focus-visible 由 CssBaseline 的 outline 提供。compact 退化为纯图标 + Tooltip，点击跳转 `/collections`，不展开树。展开后子项经 `NavChildLeaf` 渲染为**缩进的叶子链接**（`component={RouterLink}` 指向 `child.path`，同一 `navActiveSx` 高亮，若 `child.icon` 存在则在文字前渲染 20px 固定图标槽）。**子叶 active 判定 = 最长前缀匹配**（`nav-active.ts` 的 `findActiveChildPath`，段边界前缀 + 最长者胜，兄弟叶互斥）——sibling 叶（`/collections/bilibili`、`/collections/github`）不互相前缀，天然互斥；最长者胜用于把嵌套详情路由 `/collections/bilibili/:id` 归属 bilibili 叶。**鱼骨连接线**：每个叶子自己用 `::before`（竖脊段）+ `::after`（横肋 `FISHBONE_RIB=14px`）画出与父项的连接，颜色消费 `theme.vars.palette.divider`；最后一个叶子竖脊只到横肋中点收成 L 形拐角；竖脊对齐父项图标竖轴（子容器 `ml: NAV_CHILD_INDENT=3` = 行 pl 12 + 图标半宽 12 = 24px），叶子按钮 `ml` 让高亮 pill 让开横肋区。子项来自 `collectionPlatformRegistry`，**不再往下展开收藏夹**——收藏夹列表留在平台页内过滤器。nav 不消费收藏夹数据，无全局 provider
- `dashboard/nav.tsx` 平台叶子颜色契约 — `nav-config.tsx` 从 `collectionPlatformRegistry` 将 `child.platform` 传入 `NavChildLeaf`；非 active 平台图标槽消费 `theme.vars.palette.platform[platform]`，active 由共享 `navActiveSx` 覆盖为珊瑚，Platform Request 外链保持禁用色。平台身份色不用于导航文字、背景或连接线。
- `nav-active.ts` — `findActiveChildPath(pathname, childPaths)` 纯函数（单测 `nav-active.test.ts`）：兄弟子叶的 active 路径解析，段边界前缀匹配（`===` 或 `path/` 前缀）+ 最长匹配胜出，无匹配返回 null
- `nav-config.tsx` — `createNavData(preferredPlatforms)` 是导航策略唯一入口；顶层顺序固定为 Collections、Analytics（`/`）、Chat、Settings。从 `app/collection-platform-registry.ts` 的 canonical 元数据稳定分区，选中平台在前、未选平台在后，两组内部保持 registry 顺序且全部平台恰好一次；末尾追加**Platform Request 外链叶子**（`external: true`，`path` 直接放 `lib/repo.ts` 的预填 new-issue URL——它是动作不是平台，刻意不进 registry）。模块不导出可变/静态 nav 单例。`NavItem.external` 让 `NavChildLeaf` 渲染 `<a target="_blank" rel="noopener noreferrer">` 而非 RouterLink：文字 `text.disabled` 淡化 + 尾部 `eva:diagonal-arrow-right-up-fill` 外链箭头，active 匹配对 https URL 天然不命中故永不高亮

## 约定

- 侧边栏 Pin/Unpin: `sidebarPinnedStorage`（`lib/storage/ui-state.ts`），布尔值存储在 `local:sidebarPinned`（默认 true）。DashboardLayout 读取并通过 Header toggle 按钮切换。Pinned=300px 展开（图标+文字），Unpinned=88px compact 图标栏（MUI Tooltip 显示菜单名）。Mobile（md 以下，<900px）不受影响，始终 Drawer 模式
- 拒绝清单（docs/23 §11）：Header 不加页面搜索、账号、workspace、通知中心；nav 不做 horizontal 模式、不加 upgrade 卡；不引入 `motion`
- nav 嵌套：主 sidebar 只做**一级嵌套**（Collections 父项 → 平台叶子链接），止于平台名，不展开收藏夹。收藏夹数据仍由各平台 section 拥有，nav 不读取。`Onboarding Platform Preference` 仅决定子叶优先级，禁止隐藏平台或反向重排 registry；新增平台更新 `lib/collections/platforms.ts` + `app/collection-platform-registry.ts` 后会自动落在未选组。active 互斥由 `nav-active.ts` 最长前缀匹配保证
