# sections/x

X (Twitter) 书签收藏页（`/collections/x`，扁平单集合无详情路由，第四个平台）。视觉结构对齐 GitHub Stars 收藏页（`sections/github-stars/`）：顶栏（标题+计数+lastSynced+同步按钮）→ 同步进度条 → 搜索框 → 作者 chips → 卡片 grid（xs12/sm6/md4/lg3）+ Pagination。**数据一律从 PGlite 经 `lib/x/x-sync-service` 查询方法读取（UI 零 drizzle 导入），不直读 X GraphQL API**；同步（`syncBookmarks`）在 app.html context 跑，经 RPC proxy 写 Offscreen PGlite。**凭据无 UI 半（D6）**：无 Connections 卡、无 `UserSettings.xToken`——认证由 background `webRequest` 从用户浏览 x.com 的真实请求中捕获完整 `Cookie`+csrf+bearer（见 `lib/x/x-auth.ts`），同步时 hook 先 `getXAuth()` 读 session 存储（app.html 是 storage-capable context）再传入 `syncBookmarks(auth)`；未捕获到（用户本 session 没访问过 x.com）auth 为 null 由 lib 层抛 `XAuthError`，UI 映射为「打开 X 书签页」空态（deep-link `x.com/i/bookmarks`，登录后页面右下角有浮层「获取书签」按钮，见 `entrypoints/x-bookmarks.content/`）。

## 模块结构

- `x-view.tsx` — 主视图：展示脚手架全部消费 `components/collection/` 哑组件（StateBox/SectionTitleBar/SearchField/CardGrid/`ErrorState`/`NoMatchesState`/`SyncNowButton`/`SyncProgressBar`），本文件保留编排 + 平台文案（NotLoggedInState/EmptyLibraryState 是 StateBox 薄包装，TweetGridSkeleton 见下）。**无 token 门（不同于 github）**：登录态在同步时才校验——`syncError.kind==='auth'`（authFailed）时内容区短路为 `NotLoggedInState`；从未同步（lastSyncedAt null，库空）显示 `EmptyLibraryState`。**两个空态共用同一对动作按钮**（`OpenBookmarksButton` 主 + `SyncNowButton` 次）：主路径引导打开 `x.com/i/bookmarks` 浮层按钮获取（对标 supermemory 的页面内导入 UX），立即同步降为次要按钮。**内容分支顺序不在此维持**——由共享纯函数 `resolveCollectionPhase`（`app/hooks/collection-phase.ts`）返回 phase，本 view 只做 `switch(phase)` → 平台节点映射。库有数据时 syncError 降级为顶部错误横幅（数据仍展示）。**i18n seam**：hook 返回结构化 `XSyncError`（auth / rate-limit+resetAt / unknown），模块级 `syncErrorMessage()` 在此映射为文案（`x.notLoggedInTitle` / `x.rateLimited(NoReset)`）；组件内 `useTranslation()` 订阅。**同步进度 `SyncProgressBar` 恒 indeterminate**（不传 value）——游标分页无总页数可知，只显示「已拉取 N 条（第 P 页）」（`x.syncProgress`）。标签接线一律经 `useCollectionTags(PLATFORM, tweetIds)`（`components/tags/`）——五件套（批量页标签 + 单 `TagEditPopover` + 作者 chips 下方 `TagFilterChips`/`useTagFilter`）+ `handleTagsChanged` 不变量封在 hook 内，view 直接把它传给 `TagEditPopover`/`TaggedItemGrid` 的 onChanged/onTagsChanged；`renderCard` 传 `TaggedTweetCard`、`skeleton` 传 `TweetGridSkeleton`
- `use-x-bookmarks.ts` — 数据 hook：共享 `useCollectionLibrary`（`app/hooks/`，见该目录 CLAUDE.md）的薄 adapter——状态机全在泛型层，本文件只注入模块级 `queryFn`（filter→author 映射 `getBookmarks`，publishedAt 降序服务层固定）、`facetsFn=getAuthorCounts`、`lastSyncedFn`、`syncFn`、`classifyXSyncError`，并把泛化字段映射回 bookmarks/author/authors 命名。**auth 解析留在 syncFn 闭包**（不读 useSettings）——sync 时 `getXAuth()` 后调 `syncBookmarks(auth)`（auth 是显式参数：该函数也跑在无 `chrome.storage` 的 offscreen 里，storage 读取必须留在调用方），auth null 抛 `XAuthError`；进度回调 `(fetchedCount, page)` 恒 indeterminate。错误分类 `classifyXSyncError`（`XSyncError` 类型 + 分类器在 `lib/x/x-messages.ts`，与 x.com 浮层按钮共用，本 hook re-export `XSyncError` 供 view 沿用旧 import；翻译留给 view）。同步是**手动按钮触发（D5，绝不 auto-on-mount）**——端点是限流远程。**注意**：这是 X 同步的两个触发点之一，另一个是 x.com 书签页浮层按钮（`entrypoints/x-bookmarks.content/`，经 Offscreen 跑同一个 `syncBookmarks`），两者数据一致
- `author-chips.tsx` — 作者 chip 行：共享 `ChipRowShell`（twitter icon + `x.authorsTitle`）+ `FilterChip`（maxWidth 220）——「全部(N)」chip + 各作者「显示名 (count)」（服务层已按数量降序），value 为 author handle。库空时由 view 隐藏整行。**折叠**（作者数无上界，异于有界的文件夹/语言 chip）：本地 `expanded` state，折叠时只渲染前 `COLLAPSED_COUNT=12` 个作者 chip，末尾加一个 raw MUI `Chip`（非 FilterChip，`eva:arrow-ios-downward/upward-fill` 箭头）作「展开 (+N) / 收起」切换（`x.showMoreAuthors`/`x.showLessAuthors`）；overflow≤0 不渲染切换。折叠态下若当前选中作者落在 fold 之外，额外补渲染该 selected chip（`selectedHidden`），保证激活的筛选永不隐藏
- `x-card.tsx` — 推文卡片（不复用 RepoCard）：作者头像（Avatar，无图回退 twitter icon）+ 显示名（noWrap）+ @handle + 推文正文（3 行 clamp，`whitespace: pre-wrap`）+ 首张 media 缩略图（`<img>` 96 高，若有）+ 底部行（点赞/转推/回复计数 `formatCompactNumber` + `formatDateTime(publishedAt)`）+ 标签行（共享 `TagRow`，CardActionArea **之外**防误触 `window.open` 跳转；`tags?` undefined 时整区不渲染）。`XCardProps { bookmark, tags?, onEditTags? }`。点击 `window.open(originalUrl)`。`useTranslation()` 订阅保证 locale 切换 re-render 格式化输出。`StatItem.icon` 类型为 `IconifyName`（`register-icons`）保类型安全
- `tagged-tweet-card.tsx` — `TaggedTweetCard`：TaggedItemGrid `renderCard` 的 X 卡片 adapter。`toXBookmarkItem` 把平台无关 `TaggedItem` 映射回 `XBookmarkItem`（originalUrl 取 `item.originalUrl`；platformMeta 收窄委托 sync-service 导出的 `narrowXMeta`（SSOT，mapRow 与本 adapter 共用，含 `narrowMedia` 逐项校验 `{type,url}`），本文件只装 envelope 字段 + spread）。`publishedAt` 置 null（TaggedItem 无该字段）。**adapter 知识归 adapter**：`XBookmarkItem` 类型导入只在本文件
- `tweet-grid-skeleton.tsx` — `TweetGridSkeleton`：共享 `CardGridSkeleton` 外壳（grid-of-8）+ rounded 200 高（匹配推文卡片），view 与 TaggedItemGrid（`skeleton` prop）共用

## 约定

- 排序固定 publishedAt 降序（MVP 无排序控件）；platformMeta 形状见 `lib/x/CLAUDE.md`
- 三种空态：未登录（NotLoggedInState）/ 库空（EmptyLibraryState）——两者均为「打开 X 书签页」主按钮 + 「立即同步」次按钮 / 同步失败（ErrorState+retry）；虚线框为共享 `StateBox`
- 路由/导航：`main.tsx` 路由 `collections/x`（**无 `:id` 详情路由**——扁平单集合）+ `nav-config.tsx` Collections children 叶子（`nav.xBookmarks`）；兄弟叶 active 互斥判定见 `layouts/nav-active.ts`（最长前缀匹配）
- 标签：手动打标已接入（共享 `components/tags/` 模块，platform='x'）；AI 自动打标已接线（docs/16 MEDIUM-2）——`use-x-bookmarks.ts` syncFn 在 `syncBookmarks` 返回后 `void tagNewItems('x', result.newItemIds)` fire-and-forget（触发点必须在本 hook：lib/x 也跑在无 chrome.storage 的 offscreen，不能 import tagging；x.com 浮层路径不打标，欠账见 `lib/x/CLAUDE.md`）。`x-card` 用的 `mdi:twitter`/`mdi:heart-outline`/`mdi:repeat-variant`/`mdi:comment-outline` 图标在 `components/iconify/icon-sets.ts` 离线注册
- i18n：平台特有文案 key 在 `x.*`（zh/en 齐全，`x.noMatches` 保留平台名词）；通用文案（retry/syncNow/loadFailed）走共享 `common.*`；错误类映射在 view 边界（lib 层只抛结构化错误）；无硬编码 CJK（`tests/i18n-no-hardcoded.test.ts` 守卫）
