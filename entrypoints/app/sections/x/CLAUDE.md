# sections/x

X (Twitter) 书签收藏页（`/collections/x`，扁平单集合无详情路由，第四个平台）。视觉结构对齐 GitHub Stars 收藏页（`sections/github-stars/`）：标题行（h5 视觉 / h1 语义 + 计数 + lastSynced + **本次新增 N** + 同步按钮）→ pipeline 行（strip + 闸门）→ 全宽搜索框 → 配置提醒横幅（若有）→ 作者 chips → 卡片 grid（xs12/sm6/md4/lg3）+ Pagination。**数据一律从 PGlite 经 `lib/x/x-sync-service` 查询方法读取（UI 零 drizzle 导入），不直读 X GraphQL API**；同步（`syncBookmarks`）在 app.html context 跑，经 RPC proxy 写 Offscreen PGlite。**X 同步单一入口 = app.html**（07-20 删除 x.com 浮层按钮及其整条 CS→bg→offscreen→tab 管线；浮层冗余，auth 捕获链保留即可自同步）。**凭据无 UI 半（D6）**：无 Connections 卡、无 `UserSettings.xToken`——认证由 background `webRequest` 从用户浏览 x.com 的真实请求中捕获完整 `Cookie`+csrf+bearer（见 `lib/x/x-auth.ts`），同步时 hook 先 `getXAuth()` 读 session 存储（app.html 是 storage-capable context）再传入 `syncBookmarks(auth)`；未捕获到（用户本 session 没访问过 x.com）auth 为 null 由 lib 层抛 `XAuthError`，UI 映射为「打开 x.com/i/bookmarks 登录，让扩展捕获会话后回来点同步」空态（deep-link）。

## 模块结构

- `x-view.tsx` — scaffold Adapter；常驻 pipeline 为 Fetch → Embedding/Tagging 并行（无 content 段），段装配/标签/coverage key 经共享 `useCollectionPipeline`（`app/hooks/`，docs/20 中-7），本 view 只传 `backgroundJobRuntime(syncJob, fetchedCountProgress)`；Search 后注入共享 provider Configuration Blocker notice。auth/cooldown、runtime、caption、phase 与标签职责不变。
- `x-sync-adapter.ts` — 共享 Sync Adapter（audit #6）：`runXBookmarksSync(onProgress, control)` 单点定义「X 同步成功意味着什么」——**auth 解析在此**（`getXAuth()` 后调 `syncBookmarks(auth)`：auth 是显式参数，该函数 import-safe for offscreen，storage 读取必须留在调用方；auth null 由 lib 抛 `XAuthError`）、进度映射 `(fetchedCount, page)` 恒 indeterminate（`XSyncProgress` 在此定义）、`startCollectionProcessingJobs` 派发（job namespace 经 `jobPlatformForCollection` SSOT）、成功后写 `xLastSyncStorage.setValue({syncedAt, inserted})`（**手动与 daily auto 两触发都写**——修复自动同步不更新「本次新增」的漂移）。手动页面 `syncFn` 与 daily registry 引用**同一函数**。契约测试 `x-sync-adapter.test.ts`；另导出 `xAutoSyncPolicy`（daily 触发策略：`getXAuth()` 非 null 且 `remainingCooldown` 为 0——跨日边界仍尊重 5 分钟冷却），app 根 `collection-platform-auto-sync.ts` 将其与 Sync Adapter 配对进 daily registry（docs/20 高-3）
- `use-x-bookmarks.ts` — 数据 hook：共享 `useCollectionLibrary`（`app/hooks/`，见该目录 CLAUDE.md）的薄 adapter——状态机全在泛型层，本文件只注入 `queryFn`（filter→author 映射 `getBookmarks`，publishedAt 降序服务层固定）、`facetsFn=getAuthorCounts`、`lastSyncedFn`、`syncFn=runXBookmarksSync`（模块级引用稳定）、`classifyXSyncError`，并把泛化字段映射回 bookmarks/author/authors 命名。错误分类 `classifyXSyncError`（`XSyncError` 类型 + 分类器在 `lib/x/x-messages.ts`，本 hook re-export `XSyncError` + `XSyncProgress` 供 view 沿用旧 import；翻译留给 view）。同步是**手动按钮触发（D5，绝不 auto-on-mount）**——端点是限流远程（daily auto-sync 另有冷却感知 probe）。**X 专属 UI 逻辑（不入共享状态机）**：订阅 `xLastSyncStorage`（getValue + watch）派生 `lastInserted` 与冷却 seed——写入方是共享 adapter，故自动同步落库后本页 caption/冷却同样实时刷新。**冷却源** = `max(lib.lastSyncedAt（DB sources.lastFetchedAt，跨刷新持久）, storage.syncedAt（同步 resolve 即落））`，经纯函数 `remainingCooldown`（见 `cooldown.ts`）算剩余；窗口内每秒 `setInterval` tick 驱动倒计时，窗口外清 timer。暴露 `lastInserted`/`cooldownRemainingMs` 给 view
- `cooldown.ts` — X 专属同步冷却纯函数（可测）：`COOLDOWN_MS=5*60*1000`；`remainingCooldown(lastSyncedAt: number|null, now)` 返回剩余 ms（null/窗口外→0，clock skew→满窗口锁死）；`formatCountdown(ms)` → `mm:ss`（秒向上取整，窗口内不显 0:00）。单测 `cooldown.test.ts`（窗口内/外/边界/skew）。**判定源 = 成功同步时间**（DB lastFetchedAt 仅成功刷新 + storage.syncedAt 兜底），故失败同步不锁按钮
- `author-chips.tsx` — 作者 chip 行：共享 `ChipRowShell`（twitter icon + `x.authorsTitle`）+ `FilterChip`（maxWidth 220）——「全部(N)」chip + 各作者「显示名 (count)」（服务层已按数量降序），value 为 author handle。库空时由 view 隐藏整行。**折叠**（作者数无上界，异于有界的文件夹/语言 chip）：本地 `expanded` state，折叠时只渲染前 `COLLAPSED_COUNT=12` 个作者 chip，末尾加一个 raw MUI `Chip`（非 FilterChip，`eva:arrow-ios-downward/upward-fill` 箭头）作「展开 (+N) / 收起」切换（`x.showMoreAuthors`/`x.showLessAuthors`）；overflow≤0 不渲染切换。折叠态下若当前选中作者落在 fold 之外，额外补渲染该 selected chip（`selectedHidden`），保证激活的筛选永不隐藏
- `x-card.tsx` — 推文卡片 = 共享 `CollectionCard` 装配：`header` 作者头像（Avatar 24px，无图回退 twitter icon）+ 竖排两行：显示名（noWrap + title）/ @handle（noWrap + title），两行各占整行宽度不互相挤压；`title` = 推文正文（`normalizeTweetText`：`\n{2,}` → `\n` 防 clamp 内孤立「…」行，3 行 clamp，**不用 `pre-wrap`**，`text` 空时回退 `title`）；`media` 首张 media 作 `1/1` 72px 方缩略图，外壳放在正文右侧、header 之下（若有；破图回退 twitter icon，docs/19 P0-2 破图修复）；`date` `formatDateTime(publishedAt)`（外壳右格 noWrap 不再截成「9:09 P…」）；`stats` 点赞/转推/回复 `formatCompactNumber`；`tags`（共享 `TagRow`，外壳保证在链接之外；undefined 时整行不渲染）。`XCardProps { bookmark, tags?, onEditTags? }`。`href = originalUrl` 真实锚点新标签打开（不再 `window.open`）。`useTranslation()` 订阅保证 locale 切换 re-render 格式化输出。`StatItem.icon` 类型为 `IconifyName`（`register-icons`）保类型安全
- `tagged-tweet-card.tsx` — `TaggedTweetCard`：TaggedItemGrid `renderCard` 的 X 卡片 adapter。`toXBookmarkItem` 把平台无关 `TaggedItem` 映射回 `XBookmarkItem`（originalUrl 取 `item.originalUrl`；platformMeta 收窄委托 sync-service 导出的 `narrowXMeta`（SSOT，mapRow 与本 adapter 共用，含 `narrowMedia` 逐项校验 `{type,url}`），本文件只装 envelope 字段 + spread）。`publishedAt` 置 null（TaggedItem 无该字段）。**adapter 知识归 adapter**：`XBookmarkItem` 类型导入只在本文件
- `tweet-grid-skeleton.tsx` — `TweetGridSkeleton`：共享 `CardGridSkeleton` 外壳（grid-of-8）+ rounded 200 高（匹配推文卡片），view 与 TaggedItemGrid（`skeleton` prop）共用

## 约定

- 页面顺序由共享 scaffold 固定为标题/系统状态 → 搜索 → 配置提醒 → 作者主分类 → 标签 → 列表；本目录只提供 adapter。
- 排序固定 publishedAt 降序（MVP 无排序控件）；platformMeta 形状见 `lib/x/CLAUDE.md`
- 三种空态：未登录（NotLoggedInState）/ 库空（EmptyLibraryState）——两者均为「打开 X 书签页」主按钮（deep-link `x.com/i/bookmarks`，引导登录让扩展捕获会话）+ 「立即同步」次按钮 / 同步失败（ErrorState+retry）；虚线框为共享 `StateBox`
- 冷却（X 专属，其他平台无）：成功同步后 5 分钟硬禁用同步按钮 + mm:ss 倒计时 label，判定源 = DB `sources.lastFetchedAt`（跨刷新持久）+ 本会话 seed（即时锁）。逻辑封在 `use-x-bookmarks.ts` + `cooldown.ts`，经 scaffold `syncDisabled`/`syncDisabledLabel` 可选 props 下传到 `SectionTitleBar`——**不改共享 `useCollectionLibrary`**，其他平台不传 = 现状不变
- 本次新增数：`xLastSyncStorage`（`local:x-last-sync`，`{syncedAt, inserted}`）持久「本次新增 N」跨刷新，共享 Sync Adapter 成功后写入（手动/自动同源），hook 经 watch 订阅；view caption 追加 `x.newThisSync` 段（legacy 库 storage 空则省略）
- 路由/导航：`main.tsx` 路由 `collections/x`（**无 `:id` 详情路由**——扁平单集合）+ `nav-config.tsx` Collections children 叶子（`nav.xBookmarks`）；兄弟叶 active 互斥判定见 `layouts/nav-active.ts`（最长前缀匹配）
- AI 后处理由 `x-sync-adapter.ts` 把 `newItemIds` 交给 `startCollectionProcessingJobs`（手动/自动两触发同源），共享 `x-bookmarks:embed|tag` 串行 lanes；领域 platform `'x'` 与 job namespace `'x-bookmarks'` 继续分离。
- i18n：平台特有文案 key 在 `x.*`（zh/en 齐全，`x.noMatches` 保留平台名词；`x.newThisSync` 带 `.one` 复数变体、`x.cooldown` 承接 `{{time}}`）；通用文案（retry/loadFailed）走共享 `common.*`，获取按钮走 `pipeline.fetchNow`（`common.syncNow` 已删）；错误类映射在 view 边界（lib 层只抛结构化错误）；无硬编码 CJK（`tests/i18n-no-hardcoded.test.ts` 守卫）
