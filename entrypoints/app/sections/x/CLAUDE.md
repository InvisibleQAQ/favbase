# sections/x

X (Twitter) 书签收藏页（`/collections/x`，扁平单集合无详情路由，第四个平台）。视觉结构对齐 GitHub Stars 收藏页（`sections/github-stars/`）：28px route h1 + 计数 + lastSynced + **本次新增 N** + 同步按钮 → pipeline 行（strip + 闸门）→ 全宽搜索框 → 配置提醒横幅（若有）→ 作者 chips → 卡片 grid（xs12/sm6/md4/lg3）+ Pagination。**数据一律从 PGlite 经 `lib/x/x-sync-service` 查询方法读取（UI 零 drizzle 导入），不直读 X GraphQL API**；同步（`syncBookmarks`）在 app.html context 跑，经 RPC proxy 写 Offscreen PGlite。**X 同步单一入口 = app.html**（07-20 删除 x.com 浮层按钮及其整条 CS→bg→offscreen→tab 管线；浮层冗余，auth 捕获链保留即可自同步）。**凭据无 UI 半（D6）**：无 Connections 卡、无 `UserSettings.xToken`——认证由 background `webRequest` 从用户浏览 x.com 的真实请求中捕获完整 `Cookie`+csrf+bearer（见 `lib/x/x-auth.ts`），同步时 adapter 先 `getXAuth()` 读 session 存储（app.html 是 storage-capable context）再传入 `syncBookmarks(auth)`；未捕获到（用户本 session 没访问过 x.com）auth 为 null 由 adapter 在 Platform Sync funnel **之前**抛 `XAuthError('missing')`（不算尝试、不写记录，docs/32 §5.2），UI 映射为「打开 x.com/i/bookmarks 登录，让扩展捕获会话后回来点同步」空态（deep-link）；X 拒绝已捕获的会话（401/403）时 reason 为 `'rejected'`，横幅与空态改用 `x.sessionRejected*`「登录已失效，重新登录」（docs/32 Step 4）。

**面包屑**（docs/25 Step 8）：`useCollectionBreadcrumbs('x')` → `首页 / 收藏夹 / X 书签`。

## 模块结构

- `x-view.tsx` — scaffold Adapter；常驻 pipeline 为 Fetch → Embedding/Tagging 并行（无 content 段），段装配/标签/coverage key 经共享 `useCollectionPipeline`（`app/hooks/`，docs/20 中-7），本 view 只传 `backgroundJobRuntime(syncJob, fetchedCountProgress)`；Search 后注入共享 provider Configuration Blocker notice。auth/cooldown、runtime、caption、phase 与标签职责不变。状态组件来自 `components/collection-states/`（docs/32 Step 6）：模块级 `X_BOOKMARKS_SITE`（`SiteAction`：`x.com/i/bookmarks` + `x.openBookmarksPage` + `mdi:twitter`）同时传给 `EmptyLibraryState` 与 `NotLoggedInState`，所以两态都是「打开 X 书签页」在前、获取 soft 在后；未登录态的两套文案（`x.notLoggedIn*` / `x.sessionRejected*`）由 view 按 `authReason` 选键，组件不认识 `reason`。`copy` 只传平台文案，外壳文案由 scaffold 自取；caption 的「上次同步」用 `common.lastSynced`。作者 chips 是共享 `FacetChips`（`components/collection-states/`，docs/32 Step 8：`icon="mdi:twitter"` + `x.authorsTitle`，`getKey` = `authorHandle`、`getName` = `authorName`，「显示名 (count)」、名字为空回退 handle，顺序是 `getAuthorCounts` 给的计数降序；原 `author-chips.tsx` 已删），库空时 view 隐藏整行。
- `x-sync-adapter.ts` — 共享 Sync Adapter（audit #6）：`runXBookmarksSync(onProgress, control)` 单点定义「X 同步成功意味着什么」——**auth 解析在此**（`getXAuth()` 后调 `syncBookmarks(auth)`：auth 是显式参数，该函数 import-safe for offscreen，storage 读取必须留在调用方；auth null 在 funnel 之前由本文件抛 `XAuthError('Not logged in to x.com', 'missing')`——lib 的 `syncBookmarks` 自 docs/32 Step 1 起只收 `XAuth`，null 分支已删，页面未登录态照旧靠这个错误类识别）、进度映射 `(fetchedCount, page)` 恒 indeterminate（`XSyncProgress` 在此定义）、整段 `syncBookmarks` 经 `hooks/platform-sync.ts` 的 funnel `runPlatformSync('x', control, sync)`，回报 `{ fetched: total, inserted, newItemIds }`——funnel 记尝试、成功时派发 embed/tag lanes（job namespace 在 funnel 内派生）并把 `inserted` 写进 Platform Sync Record 的 `last_inserted`（**手动与 daily auto 两触发同源**，「本次新增」与冷却锚点随之同步刷新；原 `xLastSyncStorage` 已删）。手动页面 `syncFn` 与 daily registry 引用**同一函数**。契约测试 `x-sync-adapter.test.ts`；另导出 `xAutoSyncPolicy`（daily 触发策略：`getXAuth()` 非 null 且 `remainingCooldown` 为 0——跨日边界仍尊重 5 分钟冷却），app 根 `collection-platform-auto-sync.ts` 将其与 Sync Adapter 配对进 daily registry（docs/20 高-3）
- `use-x-bookmarks.ts` — 数据 hook：共享 `useCollectionLibrary`（`app/hooks/`，见该目录 CLAUDE.md）的薄 adapter——状态机全在泛型层，本文件（60 行，docs/32 Step 7）只注入模块级 `queryFn = facetQuery(getBookmarks, 'author')`（publishedAt 降序服务层固定）、`facetsFn=getAuthorCounts`、`lastSyncedFn`、`syncFn=runXBookmarksSync`、`jobPlatform = JOB_PLATFORM`（模块级引用稳定），返回 `{ ...lib, lastInserted, cooldownRemainingMs }`——**不改名、无手写返回接口、不再 re-export `XSyncProgress`**（零消费者），view 直接读 `items`/`filter`/`setFilter`/`facets`。错误分类不在本 hook：`syncError` 是共享 `useCollectionLibrary` 按基类分类好的 `CollectionSyncError`（`lib/x/x-messages.ts` 与 `XSyncError` 已删，docs/32 Step 4）。同步是**手动按钮触发（D5，绝不 auto-on-mount）**——端点是限流远程（daily auto-sync 另有冷却感知 probe）。**X 专属 UI 逻辑（不入共享状态机）**：`lastInserted` 由一个 effect 读 Platform Sync Record（`getPlatformSyncRecord('x', await initDbProxy())?.lastInserted`），依赖 `lib.syncJob.generation`——generation 只在成功时 bump，正与 `last_inserted` 只在成功时变一致，故自动同步在本页挂载期间完成同样刷新 caption（docs/32 Step 1，取代 `xLastSyncStorage` 的 getValue + watch）。**冷却源** = `lib.lastSyncedAt`（Platform Sync Record 的 `last_success_at`，跨刷新持久；同步成功后 `useCollectionLibrary` 按 generation 重取 meta 即刻更新），原「DB 与 storage 取较晚者」的双来源合并已删；经纯函数 `remainingCooldown`（见 `cooldown.ts`）算剩余；倒计时走共享 `useCountdown`（`app/hooks/use-countdown.ts`：窗口内 1 s tick、窗口外无 timer，本 hook 原来的内联 `now` state + interval 已删）。暴露 `lastInserted`/`cooldownRemainingMs` 给 view
- `cooldown.ts` — X 专属同步冷却纯函数（可测）：`COOLDOWN_MS` 自 `lib/x/cooldown.ts` re-export（`envNumber('VITE_X_COOLDOWN_MS', 300_000)`，数值是平台风控节奏故归 `lib/x/`，docs/32 Step 4；re-export 让 `cooldown.test.ts` 不改）；`remainingCooldown(lastSyncedAt: number|null, now)` 返回剩余 ms（null/窗口外→0，clock skew→满窗口锁死）。`formatCountdown` 已随倒计时搬到 `app/hooks/use-countdown.ts`（实现不变，用例一并搬走）。单测 `cooldown.test.ts`（窗口内/外/边界/skew）。**判定源 = 成功同步时间**（Platform Sync Record 的 `last_success_at`，失败尝试不动它），故失败同步不锁按钮
- `x-card.tsx` — 推文卡片 = 共享 `CollectionCard` 装配：`header` 作者头像（Avatar 24px，无图回退 twitter icon）+ 竖排两行：显示名（noWrap + title）/ @handle（noWrap + title），两行各占整行宽度不互相挤压；`title` = 推文正文（`normalizeTweetText`：`\n{2,}` → `\n` 防 clamp 内孤立「…」行，3 行 clamp，**不用 `pre-wrap`**，`text` 空时回退 `title`）；`media` 首张 media 作 `1/1` 72px 方缩略图，外壳放在正文右侧、header 之下（若有；破图回退 twitter icon，docs/19 P0-2 破图修复）；`date` `formatDateTime(publishedAt)`（外壳右格 noWrap 不再截成「9:09 P…」）；`stats` 点赞/转推/回复 `formatCompactNumber`；`tags`（共享 `TagRow`，外壳保证在链接之外；undefined 时整行不渲染）。`XCardProps { bookmark, tags?, onEditTags? }`。`href = originalUrl` 真实锚点新标签打开（不再 `window.open`）。`useTranslation()` 订阅保证 locale 切换 re-render 格式化输出。`StatItem.icon` 类型为 `IconifyName`（`register-icons`）保类型安全
- `tagged-tweet-card.tsx` — 一行 `TaggedTweetCard = taggedCard(XCard, 'bookmark', toXBookmarkItem)`（`components/tags/` 的工厂，docs/32 Step 8）：TaggedItemGrid `renderCard` 与 `/collections` `CARD_ADAPTERS` 的 X 卡片 adapter。mapper 就是 `lib/x/x-sync-service.ts` 分页查询导出的 `toXBookmarkItem`（`publishedAt` 原样取 `items.publishedAt`，meta 经 `narrowXMeta`，含 `narrowMedia` 逐项校验 `{type,url}`），本文件零 envelope 映射

## 约定

- 页面顺序由共享 scaffold 固定为标题/系统状态 → 搜索 → 配置提醒 → 作者主分类 → 标签 → 列表；本目录只提供 adapter。
- 排序固定 publishedAt 降序（MVP 无排序控件）；platformMeta 形状见 `lib/x/CLAUDE.md`
- 三种空态：未登录（共享 `NotLoggedInState`）/ 库空（共享 `EmptyLibraryState` + `site`）——两者均为 48px secondary glyph + 可换行居中动作组：「打开 X 书签页」主按钮（deep-link `x.com/i/bookmarks`，引导登录让扩展捕获会话）+ 「立即同步」次按钮 / 同步失败（ErrorState+retry）；虚线框为共享 `StateBox`
- 冷却（X 专属，其他平台无）：成功同步后 5 分钟硬禁用同步按钮 + mm:ss 倒计时 label，判定源 = Platform Sync Record 的 `last_success_at`（经 `lib.lastSyncedAt`，跨刷新持久；sync job 完成后 meta 按 generation 重取、读到新的 `last_success_at` 才上锁——比旧的 storage 写入即锁晚一次 DB 往返）。逻辑封在 `use-x-bookmarks.ts` + `cooldown.ts`，经 scaffold `syncDisabled`/`syncDisabledLabel` 可选 props 下传到 `SectionTitleBar`——**不改共享 `useCollectionLibrary`**。**限流锁**（docs/32 Step 4）：`XRateLimitError` 带 reset 时 view 另起一个 `useCountdown((now) => rateLimitRemainingMs(syncError, now))`，按钮按冷却与限流锁两者较晚者禁用，label 统一 `pipeline.fetchAvailableIn`；github 同样接限流锁，zhihu / youtube / B站的限流不带 reset 故不接。锁只作用于标题栏按钮，未登录 / 空库态 StateBox 里的按钮不受锁
- 本次新增数：Platform Sync Record 的 `last_inserted`（docs/32 Step 1，`local:x-last-sync` 已删），funnel 在成功时写入（手动/自动同源），hook 按 sync job generation 重读；view caption 追加 `x.newThisSync` 段（从未成功同步则为 null、省略）。数据对六平台都已就位，但其余五个平台页显示「本次新增」**未排期**（docs/32 Step 6 D-e：它是新功能不是去重；Step 7 同样不做——要五处 caption + 双语 i18n + 改 `useCollectionLibrary` 的 `lastSyncedFn` 契约）
- 路由/导航：`main.tsx` 路由 `collections/x`（**无 `:id` 详情路由**——扁平单集合）+ `nav-config.tsx` Collections children 叶子（`nav.xBookmarks`）；叶 active 判定见 `components/nav-section/nav-active.ts`（`isNavItemActive` 段边界匹配，平台叶 `deepMatch: true`）
- AI 后处理由 `x-sync-adapter.ts` 把 `newItemIds` 交回 Platform Sync funnel，由 funnel 派发（手动/自动两触发同源），共享 `x-bookmarks:embed|tag` 串行 lanes；领域 platform `'x'` 与 job namespace `'x-bookmarks'` 继续分离。
- i18n：平台特有文案 key 在 `x.*`（zh/en 齐全，`x.noMatches` 保留平台名词；`x.newThisSync` 带 `.one` 复数变体；`x.sessionRejectedTitle` / `x.sessionRejectedDesc` 是 `'rejected'` 那一套；按钮锁倒计时用共享 `pipeline.fetchAvailableIn`（承接 `{{time}}`，原 `x.cooldown` 已删）；通用 / 同文案走共享 `common.*`（`retry` / `loadFailed`，以及 docs/32 Step 6 收进来的 `lastSynced` / `syncFailed` / `showMore` / `showLess` / `all` / `goToSettings`——平台前缀副本已删，新平台不得再造），获取按钮走 `pipeline.fetchNow`（`common.syncNow` 已删）；错误文案是 view 模块级 `SYNC_ERROR_COPY`（`auth` / `authRejected` / `rateLimited` / `rateLimitedUntil`）交给共享 `syncErrorMessage`，不写 switch（lib 层只抛结构化错误）；无硬编码 CJK（`tests/i18n-no-hardcoded.test.ts` 守卫）
