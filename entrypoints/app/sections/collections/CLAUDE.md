# collections

app.html B站收藏夹页面组件（搜索框 + 横向收藏夹 chip + 标签筛选 chip + 视频网格，扁平竖排堆叠布局）。

## 模块结构

- `collections-view.tsx` — 收藏夹主视图：`DashboardContent` 内自上而下扁平竖排——顶部 `TextField`（`disabled` 搜索框占位，`eva:search-fill` 放大镜 adornment + `collections.searchPlaceholder`，不接搜索逻辑）→ `FolderChips`（横向收藏夹过滤器）→ `TagFilterChips`（跨夹标签筛选，选中 ≥1 标签时内容区切换为 `TaggedVideoGrid`，否则为选中夹内容 `VideoGridPanel`）。`/collections` 和 `/collections/bilibili/:mediaId` 共用组件，通过 useParams 获取 mediaId，无 mediaId 时自动 navigate(replace) 到第一个收藏夹。包含 NotLoggedIn/ErrorState/EmptyFolderState 共享状态组件 + `SortControl`（三个文字 Button + Iconify 图标的排序控件，`SORT_OPTIONS` 常量映射 mtime/view/pubtime → 图标 + i18n labelKey，选中项 primary 主色 + 下划线；渲染在 AutoTranscribeBar 下方、视频网格上方，not_logged_in/error 时不渲染）。VideoGridPanel 内接线标签：`useItemTags(bvids)` 批量加载 → 每卡传 `tags`/`onEditTags`（失效视频 attr===9 传 undefined 不渲染标签区）+ 单个 `TagEditPopover` 实例（`useTagEditState` 记录当前编辑的 bvid + anchor），编辑成功后 `refreshItemTags()` + 上抛 `onTagsChanged`（刷新筛选 chip 计数）。`selectedTagIds` 在 `usedTags` 刷新后剪枝（选中 tag 变孤儿即移出选择——否则唯一已用标签被删光时 TagFilterChips 整体消失、无"清除"按钮，用户困死在空 TaggedVideoGrid）
- `video-grid-skeleton.tsx` — `VideoGridSkeleton` 加载骨架（8 张卡片占位），VideoGridPanel 与 TaggedVideoGrid 共用
- `folder-chips.tsx` — 横向收藏夹过滤器：`collections.sidebarTitle` 小标题 + `flexWrap` 换行的 MUI `Chip` 行。选中夹 filled primary / 未选 outlined，点击 = `onSelect(folder.id)`（驱动 navigate）。**不显示 per-chip 视频数**（纯名称，选中夹计数在 VideoGridPanel 标题行）。长名 `maxWidth:200` + label 省略号；loading 渲染骨架 chip；folders 为空显示 `collections.noFolders`
- `use-bili-fav-folders.ts` — B站收藏夹 hook：调用 `bili-sync-service.fetchAndSyncFolders()` 获取列表 + 状态管理（folders/loading/syncing/loginState/error）。auth + API fetch + DB sync 全部由 service 内聚
- `video-card.tsx` — 视频卡片：封面缩略图 + 左下角播放量标签 + 右下角时长标签 + 标题 + UP主 + 收藏时间（`formatFavTime`：同年显示 MM-DD，跨年显示 N年前，自然年判断）+ 标签行（`TagRow`，CardActionArea **之外**避免误触跳转、ActionBar 之上：小号 outlined Chip（height 20）+ 行尾 `mdi:tag` IconButton 编辑入口（`tags.editTooltip`）；`tags` prop undefined 时整个区域不渲染（向后兼容），`[]` 时只显示编辑按钮无空行占位）+ 底部操作栏（转录/状态标记/进度）。失效视频灰显（attr===9）无操作栏无标签行。导出 `INVALID_ATTR = 9` 供调用方判断。操作栏三态：来源标记（CC 官方/ASR Chip，`state.indexed` 时并列"已索引"secondary Chip（`card.indexed`，database 图标）——content_state='embedded' 才显示）、转录按钮、进度条（LinearProgress + stage 文字 + 取消按钮；转录完成后本地索引期间 stage='indexing' 显示 `stage.indexing`"正在建立索引…"）
- `tag-filter-chips.tsx` — 跨夹标签筛选器：`tags.sectionTitle` 小标题（`mdi:tag` 图标）+ flexWrap Chip 行（label = `name (count)`，选中 filled primary / 未选 outlined，样式对齐 folder-chips）+ 有选中时"清除"文字按钮。**无任何已用标签时整个区域不渲染**（孤儿标签经 `getAllUsedTags` 天然隐身）
- `tagged-video-grid.tsx` — 标签筛选激活时的跨夹视频网格：`getItemsByTags(tagIds)`（AND 语义、createdAt 降序）加载 `TaggedItem`，`toBiliFavVideo` 映射回 `BiliFavVideo` 最小形状复用 VideoCard（platformMeta 取 cover/intro/duration/cnt_info/attr/type/fav_time，缺失给默认值；upper/id 用占位）。卡片不传 `transcribeState`（无操作栏），传 `tags` + `onEditTags`（自带 TagEditPopover，编辑后重查本 grid——item 不再匹配筛选时自然消失，此时 effect 自动关闭 popover 防 detached anchorEl——并上抛 `onTagsChanged`）。订阅 `'item-tagged'` 领域事件（`lib/events`）重查——后台 AI 打标命中当前筛选的视频自动出现。骨架屏只在 key（筛选组合）变化时重置；version 重查（编辑/事件）原位更新不闪骨架。空结果显示 `tags.noMatches` 虚线空态
- `tag-edit-popover.tsx` — 标签编辑 Popover + `useTagEditState()`（记录 `{ platformItemId, anchorEl }` 的 open/close 状态 hook，每个 grid 单实例）。内容：当前标签 Chip 列表（onDelete 删除）+ TextField（Enter 提交添加，IME composing 守卫，空白忽略），直接调 `addTagToPlatformItem`/`removeTagFromPlatformItem`（handler 内先 `await initDbProxy()` 防首屏点击竞态），busy 期间禁用，成功后回调 `onChanged()`
- `use-item-tags.ts` — 标签数据 hooks + `BILI_PLATFORM = 'bilibili'` 常量：`useItemTags(bvids)`（批量 `getTagsForPlatformItems` → `Record<bvid, TagRef[]>`，bvids 变化（翻页/换夹）自动重载，`refresh()` 供编辑后刷新）+ `useUsedTags()`（`getAllUsedTags` 有关联 item 的全部标签含 count，供筛选 chip）。两 hook 均订阅 `'item-tagged'` 领域事件（`lib/events`）——转录后 AI 打标落库即实时刷新：`useItemTags` 命中当前页 bvid（小写比较）才重载，`useUsedTags` 无条件重载。均先 `await initDbProxy()` 防 DB 未初始化竞态，cancelled flag 防卸载后 setState
- `use-bili-fav-videos.ts` — 收藏夹视频 hook：调用 `bili-sync-service.fetchAndSyncVideos(mediaId, page, order)` 获取视频 + goToPage 翻页 + `order`/`setOrder` 排序（`BiliFavOrder`，默认 `mtime`，切换排序经 effect 依赖重置到第 1 页重新拉取）+ loading/error/loginState 状态管理。auth + API fetch + source lookup + DB sync 全部由 service 内聚
- `use-video-transcribe.ts` — 手动视频转录 `useSyncExternalStore` 薄 hook（~58 行）：持有 `TranscriptionCoordinator` ref + 订阅 snapshot + `setVideos` 触发缓存预加载 + start/cancel 透传 + dispose。类型 re-export `VideoTranscribeState`/`ContentStatus` from `lib/bilibili/transcription-coordinator.ts`
- `use-auto-transcribe.ts` — 自动转录薄 hook（~55 行）：接收 `collectionId` + `AutoTranscribeAdapter`，创建 `AutoTranscribePipeline`（构造函数注入 adapter）+ `useSyncExternalStore` 订阅状态 + start/stop 透传 + collectionId 变更时触发 preview 查询 + unmount 时 dispose。类型 re-export from `lib/auto-transcribe/types.ts`
- `auto-transcribe-bar.tsx` — 自动转录进度 UI：全宽面板，独占 title bar 下方一行。idle 态三分支：previewLoading 时 CircularProgress 占位、pendingCount===null 时不渲染（source 未 sync）、pendingCount===0 时 check 图标 + "所有视频已转录"、其他时显示预览缩略图 + 待转录数 + "开始"按钮。运行时显示丰富进度面板（当前视频缩略图 100x60 + 标题/作者/时长/阶段文字（`stageLabel`：videoStage==='indexing' 时显示 `autoTranscribe.indexing`"正在建立索引…"，本地 chunk+embed 阶段）+ N/Total 进度计数器（N = existing + cc + asr + skipped，从 stats 推导）+ 已有/CC/ASR/跳过统计 Chip + 停止 IconButton + LinearProgress 进度条）。完成/停止后显示摘要统计 + 重新开始按钮。面板有 border + background 视觉区分。类型从 `lib/auto-transcribe/types.ts` 导入

## 约定

- B 站收藏夹: app.html Collections 页面为「搜索框 + 横向收藏夹 chip + 视频网格」扁平竖排堆叠布局（`collections-view.tsx`，无外层带边框 card 容器）。自上而下：`disabled` 搜索框占位（`FolderChips` 横向 chip 过滤器（选中 filled primary / 未选 outlined，点击 navigate 到该 mediaId）→ `VideoGridPanel`（标题栏+视频网格+分页）。`/collections` 和 `/collections/bilibili/:mediaId` 共用同一组件，通过 `useParams` 获取 mediaId 驱动内容切换，无 mediaId 时自动 navigate(replace) 到第一个收藏夹（=默认收藏夹）。搜索仅 UI 占位（无搜索逻辑），无「全部」跨夹聚合概念。`useBiliFavFolders` hook 调用 `bili-sync-service.fetchAndSyncFolders()` 获取数据并管理 UI 状态
- B 站视频持久化: `useBiliFavVideos` 调用 `bili-sync-service.fetchAndSyncVideos(mediaId, page, order)`，service 内部处理 auth + source lookup + `syncFavVideosToDb`。批量 upsert + 事务保证原子性。MVP insert-only 不更新已有记录，`content_state='pending'`
- 视频排序: 服务端排序，不做客户端排序（分页拉取时客户端只能排当前页，语义错误）。`order` 参数（`BiliFavOrder` = `mtime`|`view`|`pubtime`，均降序）贯穿 `SortControl` → `useBiliFavVideos.order` → `fetchAndSyncVideos` → `fetchFavVideos` → B站 `/x/v3/fav/resource/list?order=`，由 B站服务端对整个收藏夹排序，分页保持一致。切换排序重置到第 1 页
- RAG 索引 UI: 转录成功后 `transcribeAndPersist` await 本地 chunk+embed（见 `lib/bilibili`/`lib/embedding` CLAUDE.md），期间视频卡片 stage='indexing' / AutoTranscribeBar videoStage='indexing' 显示"正在建立索引…"（app.html 本地阶段，不走 background 推送）。已索引标记：coordinator `setVideos` 并行 `getEmbeddedBvids` 预加载 + 转录完成 onIndexed('embedded') 即时置位，`video-card.tsx` 渲染"已索引"Chip。i18n key：`stage.indexing`/`autoTranscribe.indexing`/`card.indexed`（zh/en 齐全）
- 标签 UI: 数据一律经 `@/lib/tagging`（tagging-service 是 tags schema 知识唯一持有者，本目录零 drizzle/entity/getDb 导入，同 bili-sync-service 约定）。**实时性**：转录后 AI 打标经 `'item-tagged'` 领域事件（`lib/events`）推送，`useItemTags`/`useUsedTags`/`TaggedVideoGrid` 订阅后自动重查——手动/自动转录两条路径零穿线（emit 在 tagging-service 内）；手动编辑仍走显式 `onChanged → refresh` 链路。筛选**跨收藏夹**、多选 **AND 语义**（多选收窄）；筛选激活时排序控件/AutoTranscribeBar/分页随 VideoGridPanel 一起隐藏（它们属于夹内视图）。编辑经 `TagEditPopover`（新名字自动建 tag，删除只解关联不删 tag 行）；只有转录+索引过的视频才有 AI 标签，大部分卡片无标签是正常态。i18n key：`tags.sectionTitle`/`tags.editTooltip`/`tags.addPlaceholder`/`tags.clearFilter`/`tags.noMatches`（zh/en 齐全）。标签图标 `mdi:tag`（icon-sets.ts 离线注册）
