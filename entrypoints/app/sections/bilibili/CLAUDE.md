# bilibili

app.html B站收藏夹页面组件（搜索框 + 横向收藏夹 chip + 标签筛选 chip + 视频网格，扁平竖排堆叠布局）。

## 模块结构

- `bilibili-view.tsx` — 收藏夹主视图：`DashboardContent` 内自上而下扁平竖排——顶部 `SearchField`（共享哑组件 `components/collection/`，受控——按视频标题服务端搜索当前收藏夹；搜索态提在 `BilibiliView`、300ms debounce 后下传 `VideoGridPanel`，`NoMatchesState` 区分「无匹配」与「空收藏夹」）→ `FolderChips`（横向收藏夹过滤器）→ `TagFilterChips`（跨夹标签筛选，选中 ≥1 标签时内容区切换为 `TaggedItemGrid`，否则为选中夹内容 `VideoGridPanel`）。`/collections/bilibili` 和 `/collections/bilibili/:mediaId` 共用组件，通过 useParams 获取 mediaId，无 mediaId 时自动 navigate(replace) 到第一个收藏夹。展示脚手架全部消费 `components/collection/` 哑组件（StateBox/SectionTitleBar/SearchField/CardGrid/CardGridItem/CardGridPagination，见该目录 CLAUDE.md），本文件只保留编排 + 平台文案：NotLoggedIn/ErrorState/EmptyFolderState 是 StateBox 的薄包装（B站 icon/i18n key/retry 按钮），VideoGridPanel 标题栏为 `SectionTitleBar`（caption 由 videoCount+lastSynced 拼接）+ `SortControl`（三个文字 Button + Iconify 图标的排序控件，`SORT_OPTIONS` 常量映射 mtime/view/pubtime → 图标 + i18n labelKey，选中项 primary 主色 + 下划线；渲染在 AutoTranscribeBar 下方、视频网格上方，not_logged_in/error 时不渲染）。标签接线（组件全部来自共享模块 `components/tags/`，本文件只持 `PLATFORM = 'bilibili'` 常量传参）：VideoGridPanel 内 `useItemTags(PLATFORM, bvids)` 批量加载 → 每卡传 `tags`/`onEditTags`（失效视频 attr===9 传 undefined 不渲染标签区）+ 单个 `TagEditPopover` 实例（platform 透传），编辑成功后 `refreshItemTags()` + 上抛 `onTagsChanged`（刷新筛选 chip 计数）；顶层 `useUsedTags(PLATFORM)` + `useTagFilter`（孤儿剪枝在共享 hook 内）；筛选激活时 `TaggedItemGrid` 的 `renderCard` 传 `TaggedVideoCard` adapter、`skeleton` 传 `VideoGridSkeleton`
- `video-grid-skeleton.tsx` — `VideoGridSkeleton`：共享 `CardGridSkeleton` 外壳（grid-of-8）+ B站卡片内部形态（Card+媒体块 130+两行文字），VideoGridPanel 与 TaggedItemGrid（`skeleton` prop）共用
- `folder-chips.tsx` — 横向收藏夹过滤器：共享 `ChipRowShell`（camera icon + `collections.sidebarTitle`）+ `FilterChip`（maxWidth 200），本文件保留内容逻辑——loading 骨架 chip / folders 为空显示 `collections.noFolders` / 点击 = `onSelect(folder.id)`（驱动 navigate）。**不显示 per-chip 视频数**（纯名称，选中夹计数在标题行）
- `use-bili-fav-folders.ts` — B站收藏夹 hook：调用 `bili-sync-service.fetchAndSyncFolders()` 获取列表 + 状态管理（folders/loading/syncing/loginState/error）。auth + API fetch + DB sync 全部由 service 内聚
- `video-card.tsx` — 视频卡片：封面缩略图 + 左下角播放量标签 + 右下角时长标签 + 标题 + UP主 + 收藏时间（`formatFavTime`：同年显示 MM-DD，跨年显示 N年前，自然年判断）+ 标签行（共享 `TagRow`（`components/tags/`），CardActionArea **之外**避免误触跳转、ActionBar 之上；`tags` prop undefined 时整个区域不渲染（向后兼容），`[]` 时只显示编辑按钮无空行占位）+ 底部操作栏（转录/状态标记/进度）。失效视频灰显（attr===9）无操作栏无标签行。导出 `INVALID_ATTR = 9` 供调用方判断。操作栏三态：来源标记（CC 官方/ASR Chip，`state.indexed` 时并列"已索引"secondary Chip（`card.indexed`，database 图标）——content_state='embedded' 才显示）、转录按钮、进度条（LinearProgress + stage 文字 + 取消按钮；转录完成后本地索引期间 stage='indexing' 显示 `stage.indexing`"正在建立索引…"）
- `tagged-video-card.tsx` — `TaggedVideoCard`：TaggedItemGrid `renderCard` 的 B 站卡片 adapter。`toBiliFavVideo` 把平台无关 `TaggedItem` 映射回 `BiliFavVideo` 最小形状复用 VideoCard（platformMeta 取 cover/intro/duration/cnt_info/attr/type/fav_time，缺失给默认值；upper/id 用占位）。不传 `transcribeState`（无操作栏——标签筛选网格是知识库视图非夹内视图），传 `tags` + `onEditTags`。**adapter 知识归 adapter**：`BiliFavVideo` 类型导入只在本文件，共享模块零平台导入
- `use-bili-fav-videos.ts` — 收藏夹视频 hook：调用 `bili-sync-service.fetchAndSyncVideos(mediaId, page, order, keyword)` 获取视频 + goToPage 翻页 + `order`/`setOrder` 排序（`BiliFavOrder`，默认 `mtime`）+ `keyword`（服务端标题搜索，可选参数，默认空）+ loading/error/loginState 状态管理。切换排序**或**关键词经 effect 依赖重置到第 1 页重新拉取。`fetchIdRef` 单调递增 + 每次 await 后比对，只让最新一次 fetch 写状态（防快速改 keyword/order/翻页/retry 时旧响应覆盖新结果；换夹靠 `key={selectedId}` remount 隔离，故 ref 从 0 重开）。auth + API fetch + source lookup + DB sync 全部由 service 内聚
- `use-video-transcribe.ts` — 手动视频转录 `useSyncExternalStore` 薄 hook：持有 `TranscriptionCoordinator` ref + 订阅 snapshot + `setVideos` 触发缓存预加载 + start/cancel 透传 + dispose。类型 re-export `VideoTranscribeState`/`ContentStatus` from `lib/bilibili/transcription-coordinator.ts`。**注入 `trackTranscribeRun`（模块级稳定回调）→ `startJob('bilibili','transcribe', ()=>run)`**（`background-jobs-store`）：把手动转录的 `transcribeAndPersist` promise 反映进全局「勿关本页」运行态指示器，只反映运行态（progress 恒 null indeterminate，per-video 进度仍由 section UI 显示）。promise floating（coordinator `dispose()` 不取消），故切到任意路由转录仍在跑、全局提醒不断，完成/失败/取消后 job 清除。**auto-transcribe 有意不映射**（app.html 编排、卸载即停、非 SW 持有）；Part 1 list-sync 挂载去重已 descope（`use-bili-fav-folders`/`use-bili-fav-videos` 冗余重取是 API 优化非状态丢失 bug）
- `use-auto-transcribe.ts` — 自动转录薄 hook（~55 行）：接收 `collectionId` + `AutoTranscribeAdapter`，创建 `AutoTranscribePipeline`（构造函数注入 adapter）+ `useSyncExternalStore` 订阅状态 + start/stop 透传 + collectionId 变更时触发 preview 查询 + unmount 时 dispose。类型 re-export from `lib/auto-transcribe/types.ts`
- `auto-transcribe-bar.tsx` — 自动转录进度 UI：全宽面板，独占 title bar 下方一行。idle 态三分支：previewLoading 时 CircularProgress 占位、pendingCount===null 时不渲染（source 未 sync）、pendingCount===0 时 check 图标 + "所有视频已转录"、其他时显示预览缩略图 + 待转录数 + "开始"按钮。运行时显示丰富进度面板（当前视频缩略图 100x60 + 标题/作者/时长/阶段文字（`stageLabel`：videoStage==='indexing' 时显示 `autoTranscribe.indexing`"正在建立索引…"，本地 chunk+embed 阶段）+ N/Total 进度计数器（N = existing + cc + asr + skipped，从 stats 推导）+ 已有/CC/ASR/跳过统计 Chip + 停止 IconButton + LinearProgress 进度条）。完成/停止后显示摘要统计 + 重新开始按钮。面板有 border + background 视觉区分。类型从 `lib/auto-transcribe/types.ts` 导入

## 约定

- B 站收藏夹: app.html Collections 页面为「搜索框 + 横向收藏夹 chip + 视频网格」扁平竖排堆叠布局（`bilibili-view.tsx`，无外层带边框 card 容器）。自上而下：受控搜索框 → `FolderChips` 横向 chip 过滤器（选中 filled primary / 未选 outlined，点击 navigate 到该 mediaId）→ `VideoGridPanel`（标题栏+视频网格+分页）。`/collections/bilibili` 和 `/collections/bilibili/:mediaId` 共用同一组件，通过 `useParams` 获取 mediaId 驱动内容切换，无 mediaId 时自动 navigate(replace) 到第一个收藏夹（=默认收藏夹）。搜索为服务端 keyword（仅当前收藏夹，无「全部」跨夹聚合概念）。`useBiliFavFolders` hook 调用 `bili-sync-service.fetchAndSyncFolders()` 获取数据并管理 UI 状态
- B 站视频持久化: `useBiliFavVideos` 调用 `bili-sync-service.fetchAndSyncVideos(mediaId, page, order)`，service 内部处理 auth + source lookup + `syncFavVideosToDb`。批量 upsert + 事务保证原子性。MVP insert-only 不更新已有记录，`content_state='pending'`
- 视频排序: 服务端排序，不做客户端排序（分页拉取时客户端只能排当前页，语义错误）。`order` 参数（`BiliFavOrder` = `mtime`|`view`|`pubtime`，均降序）贯穿 `SortControl` → `useBiliFavVideos.order` → `fetchAndSyncVideos` → `fetchFavVideos` → B站 `/x/v3/fav/resource/list?order=`，由 B站服务端对整个收藏夹排序，分页保持一致。切换排序重置到第 1 页
- 视频搜索: 服务端搜索，**同排序同理由**——分页拉取下客户端只能搜当前页，且本地库只缓存翻过的页会漏。`keyword` 贯穿 `SearchField`（受控）→ `BilibiliView`（300ms debounce）→ `VideoGridPanel` → `useBiliFavVideos.keyword` → `fetchAndSyncVideos` → `fetchFavVideos` → B站 `/x/v3/fav/resource/list?type=0&keyword=`（`type=0` 锁当前收藏夹）。返回 `info.media_count` 随过滤结果变化，分页公式天然复用。切换收藏夹（`handleSelectFolder`）同步清空 input+keyword（搜索是夹内语义，remounting panel 直接加载新夹全量）。tag 筛选激活时搜索框可见但不作用于 `TaggedItemGrid`（对齐 github-stars）
- RAG 索引 UI: 转录成功后 `transcribeAndPersist` await 本地 chunk+embed（见 `lib/bilibili`/`lib/embedding` CLAUDE.md），期间视频卡片 stage='indexing' / AutoTranscribeBar videoStage='indexing' 显示"正在建立索引…"（app.html 本地阶段，不走 background 推送）。已索引标记：coordinator `setVideos` 并行 `getEmbeddedBvids` 预加载 + 转录完成 onIndexed('embedded') 即时置位，`video-card.tsx` 渲染"已索引"Chip。i18n key：`stage.indexing`/`autoTranscribe.indexing`/`card.indexed`（zh/en 齐全）
- 标签 UI: 实现全部在共享模块 `components/tags/`（hooks/popover/chips/row/grid，详见该目录 CLAUDE.md），本 section 只剩**platform 传参**（`bilibili-view.tsx` 顶部 `PLATFORM = 'bilibili'` 常量）与 **renderCard 接线**（`tagged-video-card.tsx` adapter）。`useUsedTags(PLATFORM)`/`getItemsByTags(…, PLATFORM)` 平台限定：本页筛选 chips 计数与结果只含 B 站条目。筛选**跨收藏夹**、多选 **AND 语义**（多选收窄）；筛选激活时排序控件/AutoTranscribeBar/分页随 VideoGridPanel 一起隐藏（它们属于夹内视图；VideoGridPanel 卸载 → 清除筛选后重挂载自动重载标签）。只有转录+索引过的视频才有 AI 标签，大部分卡片无标签是正常态。标签图标 `mdi:tag`（icon-sets.ts 离线注册）
