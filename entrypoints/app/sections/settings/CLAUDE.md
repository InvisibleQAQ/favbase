# settings

app.html 设置页面组件（顶部分段 Tab + 三个 panel）。

## 保存模型（三张 AI 配置卡共同约定）

**无自动保存**。三卡（LLM/ASR/Embedding）编辑只改卡片内本地 draft（`useConfigDraft`），点「保存」才写 `settingsStorage`（`useSettings.saveLlm/saveAsr/saveEmbedding`，立即写入 + 记录 `configSavedAt` 时间戳）。**保存被测试连接 gating**：`canSave = verified || (dirty && 连接字段未变)`。测试通过即可保存（含与存储相同的值——幂等重写并记录 `configSavedAt`，覆盖旧自动保存遗留/env 默认起点场景）；保存成功后 verified 签名清空，按钮回禁用态。连接相关字段（LLM: provider/apiKey/model/customBaseUrl/customProtocol；ASR: provider/apiKey——model 不算，/models 探针验不了模型名；Embedding: 全部字段含 dimensions）改动使既有测试结果失效（Alert 清除 + Save 回禁用）；非连接字段（LLM temperature/maxTokens/prefMode、ASR model）改动无需重测即可保存。测试成功签名在测试**发起时**捕获（`connSig`），测试期间用户再编辑则旧签名不匹配新 draft、永不误判 verified（防 in-flight 竞态）。未保存草稿刷新/切卡即丢（有意为之，无未保存提示）。持久「已保存 + 时间」徽标来自 `settings.configSavedAt[section]`，刷新后仍在；从未手动保存过的 section 不显示。

## 模块结构

- `settings-view.tsx` — 设置页面主视图：DashboardContent + 标题"设置" + `SettingsTabs`（本地 `useState` 控制顶层 `ai`/`general`/`storage`）+ 条件渲染三个 panel。**AI 配置 panel = 两栏 Grid**：左列（`md:3`）`AiConfigNav` 竖直 rail 二级导航 + 右列（`md:9`）按本地 `aiSection` state（`'llm'|'asr'|'embedding'`，默认 `llm`）条件渲染当前区段单卡，一次只渲一张；窄屏 `xs:12` 上下堆叠。三卡 props 统一为 `{ settings, saveXxx }`（卡片内部自行 derive draft）。通用设置 panel = 语言选择 Card；存储管理 panel = 从 overview 复用的 `ExportCard`
- `use-config-draft.ts` — 三卡共享的 draft + gating hook。纯函数层（可单测，见 `use-config-draft.test.ts`）：`connectionSignature(draft, connKeys)`（连接字段 JSON 签名，undefined→null 稳定序列化）+ `computeDraftGate(draft, savedActive, connKeys, verifiedSig) → { dirty, connectionDirty, verified, canSave }`。hook 层 `useConfigDraft({ derive, connectionKeys })`：`derive(provider?)` 由卡片传入（闭包 settings，`derive()` = 已保存 active 配置，`derive(p)` = provider p 的已保存值），内部持 draft state + `touchedRef`——**外部 settings 变更仅在用户未编辑时重同步 draft**（不覆盖正在编辑的草稿）；`setField`（同值 no-op 守卫——MUI Autocomplete 挂载时 `onInputChange('reset')` 不得误标 touched）/ `switchProvider(p)`（draft 重载 p 的已保存值）/ `markVerified(sig)`（测试成功，传发起时捕获的签名）/ `markSaved()`（保存成功后重置 touched 恢复外部同步）
- `save-actions.tsx` — 三卡共享的操作行组件 `SaveActions`：测试连接按钮（outlined）+ 保存按钮（contained，`saveDisabled = !canSave`）+ 持久已保存徽标（`savedAt` 有值才渲染，`settings.savedAt` + `formatDateTime`）+ 条件 hint（`showTestHint` = 连接字段有改动未验证时显示 `settings.testBeforeSave` caption）
- `settings-tabs.tsx` — 胶囊分段 Tab 控件：MUI `Tabs` 定制（隐藏 `.MuiTabs-indicator` + `fullWidth` + 选中项 `background.paper` 白底 + `customShadows.z1` + `varAlpha` grey 底色容器）。props `{ value, onChange, tabs: SettingsTabItem[] }`。新增 tab 只需在 settings-view 的 tabs 数组加一项 + 对应 panel 条件块
- `ai-config-nav.tsx` — AI 配置 tab 内的二级导航 rail：MUI `Tabs` 定制，`md+` 竖直 rail，窄屏横向 fullWidth。`AiSection = 'llm'|'asr'|'embedding'`。label 走 i18n `settings.aiNav.*`。新增区段：加 union 值 + `aiNavItems` 项 + settings-view 右列条件块 + 双语 key
- `llm-config-card.tsx` — LLM 配置卡片：Provider 选择（`switchProvider`）+ API Key（显隐）+ Get Key 链接 + Model（Autocomplete + 远程模型列表，用 draft 的 apiKey 即时调用不需保存）+ Custom 字段 + 高级设置（temperature/maxTokens/prefMode，非连接字段）+ `SaveActions`。draft 从 `deriveLlmDraft(settings, provider?)` 派生；`getProviderDef(draft.provider)` 反映 draft 而非已保存 provider。测试成功 Alert 渲染条件 `testResult && verified`（连接字段变化即消失）；connSig 变化 effect 清 test state，provider 变化 effect 清 remoteModels。**CORS 授权**：`useHostPermission()`，test/fetchModels 前对 effective Base URL `await ensure(baseUrl)`，deny 经 `permission-error.ts` 本地化；JSX 渲染 `{dialog}`
- `asr-config-card.tsx` — ASR 配置卡片：Provider 选择 + API Key + Model（非连接字段）+ `SaveActions`。**测试连接 = `testAsrConnection`（lib/ai，GET /models 验 key）**，`canTest = !!draft.apiKey`（不要求 model）。两 provider（groq/siliconflow）均内置域名（已在静态 host_permissions），**不需要** `useHostPermission`。成功 Alert 用 `settings.asrTestSuccess`
- `permission-error.ts` — `permissionErrorKey(reason)`：host 授权 deny `reason` → `settings.permission.*` locale key（i18n seam UI 侧，LLM/Embedding 两卡共用）
- `use-host-permission.tsx` — `useHostPermission()` hook：粘合 `checkHostPermission` + `requestHostPermission`。`ensure(baseUrl)` 先分类，`needs-grant` 时开 MUI Dialog，`browser.permissions.request` 推迟到「允许」点击（保住 transient user activation）；返回 `{ ensure, dialog }`
- `embedding-config-card.tsx` — Embedding/语义搜索配置卡片：**无启用开关**（`enabled` 由 `resolveEmbeddingConfig` 派生自 apiKey）。Provider + API Key（显隐）+ Base URL + 模型 + **向量维度 Select**（「自动」= `value="auto"` 哨兵 → `undefined`——不能用 `""`，MUI Select 把空串当"未选择"；预设 `COMMON_EMBEDDING_DIMENSIONS`）+ `SaveActions` + 向量索引区。draft 从 `deriveEmbeddingDraft(settings, provider?)` 派生（resolver 值 + raw dimensions），**全部字段都是连接字段**（dimensions 影响探针返回维度）。测试连接：探针带 draft 的 `dimensions`（返回维度反映真实落库维度），`dim <= MAX_INDEXABLE_DIMENSIONS(2000)` 才 `markVerified`——**超限探针不算验证**（存了也无法入库），显 `dimensionLimitError` error Alert；成功 Alert 渲染条件含 `verified`。**向量索引区**：统计两格（`getEmbeddingStats`，挂载时 `await initDbProxy()` 幂等 join init；重建结束后刷新）+「重建向量」按钮（`rebuildPendingEmbeddings`，app.html context 直跑循环）——**rebuild 恒走已保存配置**（`resolveEmbeddingConfig(settings)`，与 indexing 同源），不看未保存 draft：先本地判 `!saved.enabled` → not-configured Alert（不为无法 embed 的 provider 弹授权），再 `ensure(saved.baseUrl)` CORS 授权；运行中禁用 + `LinearProgress` + 进度文案；结果 Alert 三态（completed/not-configured/error，失败即停可续跑）。locale key：`settings.embedding.*`。**CORS 授权**（test 用 draft baseUrl，rebuild 用 saved baseUrl）：`useHostPermission()`，deny 经 `permission-error.ts`；JSX 渲染 `{dialog}`
