# settings

app.html 设置页面组件（顶部分段 Tab + 三个 panel）。

## 模块结构

- `settings-view.tsx` — 设置页面主视图：DashboardContent + 标题"设置" + `SettingsTabs`（本地 `useState` 控制顶层 `ai`/`general`/`storage`）+ 条件渲染三个 panel。**AI 配置 panel = 两栏 Grid**：左列（`md:3`）`AiConfigNav` 竖直 rail 二级导航 + 右列（`md:9`）按本地 `aiSection` state（`'llm'|'asr'|'embedding'`，默认 `llm`）条件渲染当前区段单卡（LlmConfigCard / AsrConfigCard / EmbeddingConfigCard），一次只渲一张，消灭跨卡滚动；窄屏 `xs:12` 上下堆叠。通用设置 panel = 语言选择 Card；存储管理 panel = 从 overview 复用的 `ExportCard`
- `settings-tabs.tsx` — 胶囊分段 Tab 控件：MUI `Tabs` 定制（隐藏 `.MuiTabs-indicator` + `fullWidth` + 选中项 `background.paper` 白底 + `customShadows.z1` + `varAlpha` grey 底色容器）。props `{ value, onChange, tabs: SettingsTabItem[] }`，`SettingsTabItem` = `{ value, label, icon: IconifyName }`。新增 tab 只需在 settings-view 的 tabs 数组加一项 + 对应 panel 条件块
- `ai-config-nav.tsx` — AI 配置 tab 内的二级导航 rail：MUI `Tabs` 定制，`md+` `orientation="vertical"` 竖直 rail（左对齐图标+label），窄屏（`useMediaQuery(down('md'))`）切 `orientation="horizontal"` + `fullWidth` 横向 tab。props `{ value, onChange, items: AiConfigNavItem[] }`，`AiConfigNavItem` = `{ value: AiSection, label, icon: IconifyName }`；`AiSection = 'llm'|'asr'|'embedding'`。选中态 `primary.main` + `varAlpha(primary, 0.08)` 底色 + `customShadows.z1`。label 走 i18n `settings.aiNav.{llm,asr,embedding}`（zh-CN/en 双语）。新增区段：加 `AiSection` union 值 + `aiNavItems` 项 + settings-view 右列条件块 + 双语 `settings.aiNav.*` key
- `llm-config-card.tsx` — LLM 配置卡片：Provider 选择 + API Key（显示/隐藏）+ Get Key 链接 + Model（Autocomplete，支持远程获取模型列表）+ Custom 字段 + 测试连接（AI SDK `generateText`）。**CORS 授权**：用 `useHostPermission()` hook（`{ ensure, dialog }`），`handleTestConnection` / `handleFetchModels` 起始处对 effective Base URL（custom→`customBaseUrl`，否则 provider def）`await ensure(baseUrl)`，`!ok` 时按 `reason` 经 `permission-error.ts` 显示本地化错误并 return；JSX 里渲染 `{dialog}`。内置域名已在静态 `host_permissions` → 直接放行；未授权自定义 https 域名先弹 `use-host-permission` 的解释 Dialog，再触发 Chrome 原生授权
- `asr-config-card.tsx` — ASR 配置卡片：Provider 选择 + API Key + Model
- `permission-error.ts` — `permissionErrorKey(reason)`：host 授权 deny `reason` → `settings.permission.*` locale key（i18n seam UI 侧，两张卡共用）
- `use-host-permission.tsx` — `useHostPermission()` hook：粘合 `checkHostPermission`（分类）+ `requestHostPermission`（请求）两原语。`ensure(baseUrl): Promise<EnsurePermissionResult>` 先分类，`needs-grant`（未授权 https）时开一个 Bilitato 风格 MUI Dialog（`settings.permission.{dialogTitle,dialogDesc,grant,cancel}` + 展示 `${origin}/*`），把 `browser.permissions.request` 推迟到 Dialog「允许」按钮点击（全新用户手势，保住 transient user activation）；返回 `{ ensure, dialog }`，消费卡渲染 `{dialog}`
- `embedding-config-card.tsx` — Embedding/语义搜索配置卡片：**无启用开关**（语义搜索默认启用，`enabled` 由 `resolveEmbeddingConfig` 派生自 apiKey）。Provider 选择（`EMBEDDING_PROVIDERS`）+ API Key（显隐）+ Base URL + Embedding 模型 + **向量维度（可选，预设 Select）**，**字段恒可编辑**（默认显示 `.env.local` 值作起点，用户改动持久化并覆盖）+ **测试连接按钮（已接 `testEmbeddingConnection`）** + 向量索引区（真实统计 + 重建向量按钮，见下）。**维度 Select**（同 Provider 字段的 `TextField select` + `MenuItem` 模式）：选项 = 「自动（模型原生维度）」（`value=""` → `undefined`，不传 dimensions 参数）+ `COMMON_EMBEDDING_DIMENSIONS`（256/512/768/1024/1536，from `@/lib/embedding`，UI 不硬编码数组）；绑 `currentEmbeddingDimensions`（值恒为预设之一或 undefined），helper 恒显（说明仅部分模型支持裁剪且上限 `MAX_INDEXABLE_DIMENSIONS`）。**UI 已不可能产生无效值**（原 `dimensionsInvalid` 校验分支已删）；lib 层 `resolveEmbeddingConfig`/`embeddingProviderOptions` 仍自行过滤发不出去的值（非有限数/≤0）作为不变量。locale key：`settings.embedding.{dimensions,dimensionsAuto,dimensionsHelper}`（zh-CN/en 双份；`dimensionsPlaceholder`/`dimensionsInvalid` 已删）。测试连接：loading 态（`CircularProgress`）+ 本地 `testDimensions`/`testError` state，**探针带 `dimensions`**（`testEmbeddingConnection({..., dimensions: currentEmbeddingDimensions})`——返回维度反映真实落库维度，配 1024 裁剪的 3-large 测出 1024 而非 3072），`dim <= MAX_INDEXABLE_DIMENSIONS(2000，from @/lib/embedding)` 显 success Alert（`settings.embedding.testSuccess`，任意 ≤2000 维模型均可落库——列维度惰性跟随模型），`dim > 2000` 显 error Alert（`settings.embedding.dimensionLimitError`，超 HNSW 索引上限无法入库，引导换模型或配置维度裁剪），失败显 error Alert（`settings.embedding.testFailed`）。镜像 `llm-config-card` 测试连接 UX（`canTest = apiKey && model`）。**向量索引区（已接通）**：统计两格（已索引向量 = `embeddedChunks`、总分块数 = `totalChunks`，`getEmbeddingStats`；挂载时 `await initDbProxy()` 加载——幂等 join main.tsx 的 init，不与 `getDb()` 赛跑首屏，失败保持 `—`；重建结束后刷新）+「重建向量」按钮（`rebuildPendingEmbeddings(db, undefined, setProgress)`，app.html context 直跑循环）：点击**先本地判未配置**（`!currentEmbeddingApiKey`——该 prop 即 resolver 解析值，与 rebuild 内部 `enabled` gate 同源，未配 key 直接显 not-configured Alert，不为无法 embed 的 provider 弹权限授权）→ 再 `ensure(baseUrl)` CORS 授权（同测试连接流程，deny 走 `permissionErrorKey`），运行中禁用按钮 + `LinearProgress`（有进度 determinate / 起步 indeterminate）+ `rebuildProgress` 计数文案；结果 Alert 三态——completed（total=0 → `rebuildNoPending`，否则 `rebuildDone` 带 count 复数）、not-configured（info，`rebuildNotConfigured`）、错误（`rebuildFailed` 带 error message，失败即停、已完成条目已保存，按钮恢复可点续跑）。locale key：`settings.embedding.{totalChunks,rebuild,rebuildProgress,rebuildDone(+.one),rebuildNoPending,rebuildNotConfigured,rebuildFailed}`（旧占位 key `storageUsed/rebuildIncremental/rebuildFull/clear/notImplemented` 已随占位按钮删除）。props 由 `useSettings` 的 embedding computed（`currentEmbeddingDef`/`currentEmbeddingApiKey`/`currentEmbeddingBaseUrl`/`currentEmbeddingModel`/`currentEmbeddingDimensions`）+ `updateEmbedding` 提供。Base URL 对所有 provider 可编辑。**CORS 授权**：用 `useHostPermission()` hook（`{ ensure, dialog }`），`handleTestConnection` 对 `currentEmbeddingBaseUrl || def.baseUrl` `await ensure(baseUrl)`，`!ok` 时经 `permission-error.ts` 显示本地化错误并 return；JSX 里渲染 `{dialog}`（同 `llm-config-card`）
