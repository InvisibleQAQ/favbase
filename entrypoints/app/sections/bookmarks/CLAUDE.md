# sections/bookmarks

浏览器书签收藏页（`/collections/bookmarks` + `/collections/bookmarks/:folderId`）。视觉结构对齐 GitHub Stars 收藏页（`sections/github-stars/`）扁平堆叠：标题栏（标题+计数+lastSynced，**无同步按钮**）→ 搜索框 → 文件夹 chips（「全部」+ 各文件夹）→ 标签筛选 chips → 卡片 grid（xs12/sm6/md4/lg3）+ Pagination。**数据一律从 PGlite 经 `lib/bookmarks/bookmarks-sync-service` 查询方法读取（UI 零 drizzle 导入）**；同步（`syncBookmarks`）**挂载时自动触发一次**（镜像 bilibili fetchAndSync-on-mount，因本地读取瞬时 + insert-only 重扫便宜），无手动同步按钮；同步成功后**自动链式启动正文提取**（`use-bookmark-extraction.ts` 模块级单例 worker，路由切换不中断，标题栏下进度 caption）。

## 模块结构

- `bookmarks-view.tsx` — 主视图：展示脚手架全部消费 `components/collection/` 哑组件（StateBox/SectionTitleBar/SearchField/CardGrid/*），本文件保留编排 + 平台文案（EmptyState/ErrorState/NoMatchesState 是 StateBox 薄包装）。`SectionTitleBar` **不传 onSync**（无按钮，标题栏 sync 三件套本次改为可选）。内容分支顺序（镜像 github-stars-view）：标签筛选激活（selectedTagIds≥1）→ `TaggedItemGrid`；syncError 且库空 → ErrorState(retry=sync)；metaLoading 或（syncing 且库空）→ skeleton；库空 → EmptyState（无按钮——自动同步已跑，重扫无用，不同于 github 的连接引导）；queryError → ErrorState(retryQuery)；query loading → skeleton；筛选无结果 → NoMatchesState；否则 grid+分页。标签接线（组件全部来自 `components/tags/`，本文件只持 `PLATFORM='bookmarks'` 常量传参）：`useItemTags(PLATFORM, normalizedUrls)` 批量加载 → 每卡传 `tags`/`onEditTags` + 单 `TagEditPopover` 实例；`useUsedTags(PLATFORM)` + `useTagFilter`；`TaggedItemGrid` 的 `renderCard` 传 `TaggedBookmarkCard`、`skeleton` 传 `BookmarkGridSkeleton`。**本 view 的 `useItemTags` 顶层常驻**（不随筛选卸载），故 `onTagsChanged` 必须传 `handleTagsChanged`（refreshItemTags + refreshUsedTags），否则清除筛选后普通网格标签过期（同 github-stars-view）。标题栏下方渲染提取进度 caption（`useBookmarkExtraction()` 的 `running` 时：`CircularProgress size=12` + `bookmarks.extracting` `{{done}}/{{total}}`，idle 不渲染）
- `use-bookmark-extraction.ts` — 正文提取单例 store + hook（迷你 push-model，镜像 TranscriptionCoordinator 的 `subscribe`/`getSnapshot` 契约）：**模块级** `{running, done, total}` 状态 + listener Set，`useBookmarkExtraction()` 经 `useSyncExternalStore` 订阅。`startBookmarkExtraction()`：`running` 防重入 → `await initDbProxy()` 幂等 join → fire-and-forget `extractPendingBookmarks`（`lib/bookmarks/bookmark-content-service`），`onProgress` 推 store，`onItemExtracted` 逐条 `void tagNewItems('bookmarks',[id])` + `void embedNewItems('bookmarks',[id])`（与 use-github-stars syncFn 同触发点约定——app.html context 才有 chrome.storage）。**有意不接 AbortSignal/不随卸载中止**：app.html 内路由切换提取继续跑，关页由 pending 队列续传语义兜底
- `use-bookmarks.ts` — 数据 hook（镜像 `use-github-stars` 模式，`await initDbProxy()` 幂等 join）。挂载时 `sync()` 自动跑一次（stable 身份 → effect 只跑一次；`runningRef` 防重入，也供错误态 retry）。三组状态：分页查询（folderId/search/page/queryVersion → `getBookmarks`，`PAGE_SIZE=24`，dateAdded 降序服务层固定）；库元信息（`getFolders` + `getLastSyncedAt` + 无筛选 total 作 `libraryCount` 驱动空态判定）；同步（`syncBookmarks` 成功后 `startBookmarkExtraction()` fire-and-forget——挂载自动同步与错误态手动 retry 同路径，提取进度不触发查询 refetch）。搜索 300ms 防抖，值真正变化才重置 page=1；folderId 变化重置 page。`folderId` 来自 `useParams`（route 传入 hook），undefined = 「全部」
- `folder-chips.tsx` — 文件夹 chip 行：共享 `ChipRowShell`（folder icon + `bookmarks.foldersTitle`）+ `FilterChip`——「全部({{count}})」chip（选中态 = 无 folderId）+ 各文件夹（`maxWidth 200`，**无 per-chip 计数**，bilibili 风纯名称）。点击 = `onSelect(folderId|undefined)` 驱动 navigate
- `bookmark-card.tsx` — 书签卡片（不复用 RepoCard）：favicon（Avatar rounded，MV3 本地 `_favicon` API `chrome.runtime.getURL('/_favicon/?pageUrl=…&size=32')`，无图回退 bookmark icon）+ title（2 行截断）+ 底部行（domain + `formatDateTime(dateAdded)`）+ 标签行（共享 `TagRow`，CardActionArea **之外**防误触 `window.open` 跳转；`tags?` undefined 时整区不渲染）。`BookmarkCardProps { bookmark, tags?, onEditTags? }`。点击 `window.open(url)`。`useTranslation()` 订阅保证 locale 切换 re-render 格式化输出
- `tagged-bookmark-card.tsx` — `TaggedBookmarkCard`：TaggedItemGrid `renderCard` 的书签 adapter。`toBookmarkItem` 把平台无关 `TaggedItem` 映射回 `BookmarkItem`（url 取 `item.originalUrl`；platformMeta 防御式取 domain/dateAdded，缺失给安全默认，镜像 `toGithubRepoItem`）。**adapter 知识归 adapter**：`BookmarkItem` 类型导入只在本文件与 card
- `bookmark-grid-skeleton.tsx` — `BookmarkGridSkeleton`：共享 `CardGridSkeleton` 外壳（grid-of-8）+ rounded 96 高（匹配紧凑书签卡片），view 与 TaggedItemGrid（`skeleton` prop）共用

## 约定

- 排序固定 dateAdded 降序（MVP 无排序控件）；platformMeta 形状见 `lib/bookmarks/CLAUDE.md`
- 三种非常态：库空（EmptyState 无按钮）/ 同步失败（ErrorState+retry=sync）/ 筛选无结果（NoMatchesState）；虚线框为共享 `StateBox`
- 路由/导航：`main.tsx` 路由 `collections/bookmarks` + `collections/bookmarks/:folderId` + `nav-config.tsx` Collections children 叶子（`nav.bookmarks`）；兄弟叶 active 互斥判定见 `layouts/nav-active.ts`（最长前缀匹配，`:folderId` 详情路由归属 bookmarks 叶）。默认 `/collections/bookmarks`=「全部」，无 auto-nav 到首个文件夹（不同于 bilibili）
- 搜索限定当前选中文件夹（folderId + search 同时传 `getBookmarks`）；「全部」时搜全库
- 标签：手动打标已接入（共享 `components/tags/` 模块，platform='bookmarks'）；AI 自动打标 + 自动 embed 已接线——提取 worker 每成功一条（→'chunked'）即经 `onItemExtracted` 逐条喂 `tagNewItems`/`embedNewItems`（逐条而非 run 末：中途关页不遗留 chunked-未-embed 孤儿，chunked 不会被重取）
- icon：`solar:bookmark-bold-duotone`（nav/卡片回退）+ `solar:folder-with-files-bold-duotone`（文件夹 chip），`icon-sets.ts` 离线注册
